Instrumentele unui Web Developer

Chrome DevTools, Git, GitHub și Visual Studio Code, explicate simplu.

1. De ce avem nevoie de aceste instrumente?

  • Visual Studio Code - scriem și organizăm codul;
  • Chrome - deschidem și testăm pagina;
  • Chrome DevTools - inspectăm și depanăm pagina;
  • Git - păstrăm istoricul modificărilor;
  • GitHub - păstrăm și distribuim proiectul online.

2. Google Chrome și Developer Tools

Chrome DevTools este inclus în browserul Chrome. Nu trebuie instalat separat.

Descarcă Google Chrome Documentație DevTools

Cum deschidem DevTools?

  • click dreapta pe un element și alegem Inspect;
  • Windows/Linux: Ctrl + Shift + I sau F12;
  • Mac: Cmd + Option + I.

3. Cele mai utile panouri DevTools

Panou La ce îl folosim?
Elements Vedem HTML-ul și regulile CSS.
Console Vedem erori și testăm JavaScript.
Network Vedem fișierele cerute de browser.
Sources Vedem fișierele și depanăm JavaScript.
Device Toolbar Simulăm afișarea pe telefon sau tabletă.

4. Primul exercițiu în DevTools

  1. Deschide pagina index.html în Chrome.
  2. Dă click dreapta pe titlu și alege Inspect.
  3. În panoul Elements, schimbă temporar textul titlului.
  4. În Styles, debifează o regulă CSS.
  5. Deschide Console și scrie comanda de mai jos.
console.log("Salut din DevTools!");

Modificările făcute în DevTools sunt temporare. La reîncărcarea paginii, ele dispar dacă nu modificăm și fișierul original.

5. Ce este Git?

Git este un sistem de control al versiunilor. El ține minte modificările făcute în proiect.

  • vedem ce fișiere s-au schimbat;
  • salvăm versiuni importante ale proiectului;
  • revenim la o versiune anterioară;
  • lucrăm mai ușor împreună cu alți developeri.

Descarcă Git Documentație Git

6. Instalare și configurare Git

După instalare, deschide terminalul și verifică versiunea:

git --version

Configurăm numele și adresa de e-mail folosite în commit-uri:

git config --global user.name "Prenume Nume"
git config --global user.email "email@exemplu.ro"
git config --global --list

  • Working directory - fișierele la care lucrăm;
  • Staging area - modificările pregătite pentru salvare;
  • Commit - o versiune salvată local;
  • Remote - copia proiectului de pe GitHub.

8. Comenzi Git de bază

git status
git add .
git commit -m "Adaug pagina principală"
git push
  • git status arată situația proiectului;
  • git add . pregătește modificările;
  • git commit salvează o versiune locală;
  • git push trimite commit-urile pe GitHub.

Pentru a primi modificările remote folosim:

git pull

9. Ce este GitHub?

GitHub este o platformă online care găzduiește repository-uri Git. Git și GitHub nu sunt același lucru.

  • Git funcționează local și păstrează istoricul;
  • GitHub păstrează o copie online și permite colaborarea.

Creează cont GitHub GitHub Docs - Începe aici

10. Primul repository pe GitHub

  1. Creează un cont și verifică adresa de e-mail.
  2. Apasă New repository.
  3. Alege un nume simplu, de exemplu primul-meu-site.
  4. Creează repository-ul.
  5. Copiază adresa repository-ului.
  6. Clonează proiectul pe calculator.
git clone https://github.com/utilizator/primul-meu-site.git
cd primul-meu-site

Nu publica parole, chei API sau alte date secrete într-un repository.

11. Visual Studio Code

Visual Studio Code este editorul în care scriem și organizăm fișierele HTML, CSS și JavaScript.

Descarcă Visual Studio Code Documentație VS Code

  1. Instalează VS Code.
  2. Alege File > Open Folder.
  3. Deschide folderul proiectului, nu doar un singur fișier.
  4. Creează sau modifică fișierele din Explorer.
  5. Salvează cu Ctrl + S sau Cmd + S.

12. Zonele principale din VS Code

  • Explorer - fișierele și directoarele proiectului;
  • Editor - zona în care scriem codul;
  • Terminal - rulăm comenzi fără să părăsim editorul;
  • Source Control - vedem modificările Git;
  • Extensions - instalăm funcții suplimentare.

Terminalul integrat se deschide din meniul Terminal > New Terminal.

13. Extensii simple pentru început

  • Live Server - deschide și reîncarcă pagina locală;
  • Prettier - formatează codul automat;
  • GitLens - oferă informații suplimentare despre istoricul Git.

Instalează doar extensiile de care ai nevoie și verifică întotdeauna numele publisherului.

15. Flow complet de lucru

  1. Deschide folderul proiectului în VS Code.
  2. Modifică un fișier HTML.
  3. Salvează fișierul.
  4. Deschide pagina în Chrome cu Live Server.
  5. Folosește DevTools pentru verificare.
  6. Revino în VS Code și corectează fișierul original.
  7. Verifică modificările cu git status.
  8. Rulează git add și git commit.
  9. Trimite versiunea pe GitHub cu git push.

16. Exercițiu practic

  1. Creează un repository numit prima-lectie-web.
  2. Clonează repository-ul pe calculator.
  3. Deschide folderul în VS Code.
  4. Creează un fișier index.html cu un titlu și un paragraf.
  5. Deschide pagina în Chrome.
  6. Inspectează titlul cu DevTools.
  7. Fă primul commit și trimite-l pe GitHub.
git status
git add index.html
git commit -m "Creez prima pagină HTML"
git push

17. Recapitulare

  • VS Code este locul în care scriem codul.
  • Chrome afișează pagina.
  • DevTools ne ajută să inspectăm și să depanăm.
  • Git păstrează istoricul local.
  • GitHub găzduiește proiectul și ajută la colaborare.
