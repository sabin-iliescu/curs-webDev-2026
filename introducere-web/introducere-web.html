01 - Introducere în Web

Ce se întâmplă, pe scurt, atunci când deschidem o pagină web?

1. Ce este Internetul?

Internetul este o rețea globală care conectează calculatoare și alte dispozitive. Acestea pot trimite și primi date.

Datele sunt împărțite în bucăți mici numite pachete, trimise prin rețea și reasamblate la destinație.

Internetul poate fi comparat cu un sistem poștal foarte rapid.

2. Internetul și Web-ul nu sunt același lucru

Internet World Wide Web
Rețeaua care conectează dispozitivele. Un serviciu care funcționează prin Internet.
Transportă pagini, e-mailuri, fișiere și alte date. Conține pagini și site-uri legate prin hyperlinkuri.

Web-ul folosește în principal HTML, adrese URL și protocolul HTTP.

3. Client și server

4. Ce este o adresă IP?

Fiecare dispozitiv conectat la o rețea folosește o adresă IP pentru a putea fi identificat.

  • Exemplu IPv4: 192.168.1.10
  • Exemplu IPv6: 2001:db8::1

Putem privi adresa IP ca pe adresa unei case.

5. Ce face DNS?

DNS este agenda telefonică a Internetului. El transformă un nume ușor de reținut într-o adresă IP.

6. Ce este un URL?

URL-ul este adresa completă a unei resurse de pe Web.

https://exemplu.ro/lectii/html?nivel=incepator#titluri

  • https - protocolul;
  • exemplu.ro - domeniul;
  • /lectii/html - calea;
  • ?nivel=incepator - parametrii;
  • #titluri - secțiunea din pagină.

7. Ce este TCP/IP?

TCP/IP este un set de reguli care permite dispozitivelor să comunice prin rețea. Pentru început este suficient să reținem cele patru niveluri:

  1. Aplicație - HTTP, HTTPS, e-mail și alte servicii;
  2. Transport - TCP sau UDP transportă datele;
  3. Internet - IP găsește adresa și ruta;
  4. Acces la rețea - conexiunea fizică sau wireless.

TCP verifică dacă pachetele ajung și le reasamblează în ordinea corectă.

8. HTTP: cerere și răspuns

HTTP este protocolul folosit pentru transferul resurselor Web.

Cerere HTTP
→

→
Răspuns HTTP

Metode HTTP întâlnite des

  • GET - citește o resursă;
  • POST - trimite sau creează date;
  • PUT - actualizează date;
  • DELETE - șterge date.

9. Coduri de răspuns HTTP

Codul de stare ne spune ce s-a întâmplat cu cererea.

  • 2xx - cererea a reușit, de exemplu 200 OK;
  • 3xx - redirecționare;
  • 4xx - problemă în cerere, de exemplu 404 Not Found;
  • 5xx - problemă pe server, de exemplu 500 Internal Server Error.

10. HTTP și HTTPS

HTTPS este varianta securizată a HTTP. Datele trimise între browser și server sunt criptate.

Pentru parole, date personale și plăți trebuie folosit întotdeauna HTTPS.

12. Browserul

Browserul cere resursele, citește HTML-ul, aplică CSS-ul, execută JavaScript-ul și afișează rezultatul pe ecran.

Exemple: Chrome, Firefox, Edge, Safari și Opera.

13. Traseul complet al unei pagini

  1. Scrii un URL în browser.
  2. DNS găsește adresa IP a serverului.
  3. Browserul trimite o cerere HTTP sau HTTPS.
  4. Serverul procesează cererea.
  5. Serverul trimite un răspuns cu HTML, CSS, JavaScript sau date.
  6. Browserul construiește și afișează pagina.

14. Developer Tools

Browserul are instrumente pentru dezvoltatori. În majoritatea browserelor le poți deschide cu click dreapta și Inspect.

  • Elements - vezi HTML-ul și CSS-ul;
  • Console - vezi mesaje și erori JavaScript;
  • Network - vezi cererile și răspunsurile;
  • Application - vezi datele păstrate de site.

15. Recapitulare

  • Internetul conectează dispozitive.
  • Web-ul conectează pagini și resurse.
  • DNS transformă domeniul într-o adresă IP.
  • Browserul cere resurse de la server prin HTTP sau HTTPS.
  • Serverul răspunde, iar browserul afișează pagina.

Următorul pas: învață elementele HTML de bază.
