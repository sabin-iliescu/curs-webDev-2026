1. Funcția: o rețetă cu un nume

La cafenea, rețeta rămâne aceeași, dar comenzile diferă. O funcție primește valori, execută pași și poate întoarce un rezultat.

Intrări
12 și 2Funcție
preț × cantitateRezultat
24
function calculeazaTotal(pret, cantitate) {
  const total = pret * cantitate;
  return total;
}

const bon = calculeazaTotal(12, 2);
console.log(bon); // 24
console.log(calculeazaTotal(15, 3)); // 45
  • function începe declarația funcției.
  • calculeazaTotal este numele. Alegem un verb care descrie acțiunea.
  • pret și cantitate sunt parametri: nume folosite în interior.
  • 12 și 2 sunt argumente: valorile concrete date la apel.
  • return trimite rezultatul înapoi către codul care a apelat funcția.

Declarația pregătește rețeta; apelul, cu (), execută pașii. O funcție poate avea și zero parametri sau poate face o acțiune fără să întoarcă un rezultat util.

Același cod, alt bon

calculeazaTotal(12, 2) → 24 lei

2. return și console.log au roluri diferite

console.log() arată ceva în consolă. return oferă o valoare pe care o putem păstra sau folosi în alt calcul.

function doarAfiseaza(a, b) {
  console.log(a + b);
}

function aduna(a, b) {
  return a + b;
}

const primul = doarAfiseaza(2, 3); // Afișează 5.
console.log(primul);              // undefined: nu am returnat o valoare.
const alDoilea = aduna(2, 3);      // Nu afișează nimic singur.
console.log(alDoilea * 2);         // 10

return oprește imediat apelul curent

function imparte(a, b) {
  if (b === 0) {
    return "Nu putem împărți la zero.";
  }
  return a / b;
}

console.log(imparte(12, 3)); // 4
console.log(imparte(12, 0)); // "Nu putem împărți la zero."

În cazul lui zero ieșim din funcție înainte de împărțire. Acest tip de verificare la început se numește uneori early return.

Scrie valoarea returnată pe aceeași linie cu return. Dacă sari imediat pe linia următoare, poți obține undefined în locul rezultatului dorit.

3. Parametri impliciți: avem și o variantă de rezervă

O valoare implicită se folosește când argumentul lipsește sau este undefined.

function saluta(nume = "vizitator") {
  return `Salut, ${nume}!`;
}

console.log(saluta("Mara"));    // "Salut, Mara!"
console.log(saluta());          // "Salut, vizitator!"
console.log(saluta(undefined)); // "Salut, vizitator!"
console.log(saluta(""));        // "Salut, !" — textul gol este o valoare.
console.log(saluta(null));      // "Salut, null!" — null nu activează valoarea implicită.

Fără o valoare implicită, un parametru pentru care nu trimiți argument primește undefined. De exemplu, 2 + undefined produce NaN.

De recunoscut: arguments

O funcție obișnuită are un obiect arguments cu argumentele primite, inclusiv cele în plus față de parametrii declarați. Seamănă cu o listă, dar nu este un array obișnuit.

function primulArgument() {
  return arguments[0];
}
console.log(primulArgument("Latte", "Ceai")); // "Latte"

Funcțiile arrow nu au propriul arguments. În exercițiile noastre folosim parametri expliciți, ca să fie ușor de urmărit.

4. Variabile locale: ce se întâmplă în funcție

Parametrii și variabilele declarate în corpul funcției sunt locale. Le putem folosi acolo; nu devin automat variabile ale întregului program.

const nume = "Mara";

function pregatesteComanda() {
  const bautura = "Latte";
  return `${nume} primește ${bautura}.`;
}

console.log(pregatesteComanda()); // "Mara primește Latte."
// console.log(bautura); // Ar produce ReferenceError: este variabilă locală.

Funcția poate citi o variabilă din exterior. Pentru calcule ușor de refolosit, e util să primească datele prin parametri.

O funcție pură dă același rezultat pentru aceleași argumente și nu schimbă lucruri în exterior. calculeazaTotal(12, 2) este un exemplu: întoarce 24 fără să modifice pagina sau alte variabile.

5. Trei feluri de a scrie o funcție

Toate cele trei exemple de mai jos adună două numere. Numele diferă ca să le putem rula împreună.

Declarație de funcție

function aduna(a, b) {
  return a + b;
}
console.log(aduna(2, 3)); // 5

Function expression: păstrăm o funcție într-o variabilă

const adunaExpresie = function (a, b) {
  return a + b;
};
console.log(adunaExpresie(2, 3)); // 5

Arrow function: o formă scurtă pentru un calcul mic

const adunaArrow = (a, b) => a + b;
console.log(adunaArrow(2, 3)); // 5

const dubleaza = numar => numar * 2;
console.log(dubleaza(4)); // 8

La un singur parametru simplu putem omite parantezele. Fără acolade, expresia de după săgeată este returnată automat. Cu acolade, scriem din nou return:

const calculeaza = (pret, cantitate) => {
  const total = pret * cantitate;
  return total;
};
console.log(calculeaza(12, 2)); // 24

Funcțiile arrow nu sunt identice cu funcțiile obișnuite: de exemplu, nu au propriul this. Pentru metodele obiectelor folosim forma obișnuită din secțiunea 10.

Pot apela funcția înainte să o scriu?

O declarație function poate fi apelată mai sus în același domeniu de vizibilitate. O funcție atribuită unui const se apelează după inițializarea variabilei. Pentru început, scrie definiția înaintea apelului în ambele cazuri.

6. Callback: trimitem o acțiune altei funcții

O funcție este și o valoare: o putem păstra într-o variabilă sau trimite ca argument. O funcție transmisă astfel se numește callback. Funcția care o primește decide când o apelează.

function aduna(a, b) {
  return a + b;
}

function inmulteste(a, b) {
  return a * b;
}

function aplicaOperatia(a, b, operatie) {
  return operatie(a, b);
}

console.log(aplicaOperatia(2, 3, aduna));      // 5
console.log(aplicaOperatia(2, 3, inmulteste)); // 6

Trimitem aduna, fără (). Apoi operatie(a, b) apelează funcția primită. Dacă am trimite aduna(2, 3), am trimite rezultatul 5, nu funcția.

Schimbăm acțiunea, păstrăm numerele

aplicaOperatia(2, 3, aduna) → 5

Un callback nu înseamnă automat „mai târziu”: aici se execută imediat, în interiorul apelului. În buton.addEventListener("click", saluta), browserul îl apelează când apare clickul.

7. Listele și funcțiile lucrează bine împreună

Obiectele grupează date; listele sunt obiecte speciale, cu elemente accesibile prin index. Și funcțiile sunt obiecte speciale: pot fi apelate. Pentru început, ne concentrăm pe rolul fiecăruia.

const meniu = ["Espresso", "Latte", "Ceai"];
console.log(meniu[0]);     // "Espresso"
console.log(meniu.length); // 3

meniu.push("Cacao");       // Adaugă la final.
const ultimul = meniu.pop(); // Scoate și returnează "Cacao".
meniu.unshift("Apă");      // Adaugă la început.
const primul = meniu.shift(); // Scoate și returnează "Apă".
console.log(meniu);        // ["Espresso", "Latte", "Ceai"]

push, pop, unshift și shift modifică lista. const împiedică reatribuirea variabilei, nu modificarea conținutului ei.

for când ne trebuie indexul; for...of când ne trebuie valoarea

const preturi = [10, 15, 8];

for (let i = 0; i < preturi.length; i++) {
  console.log(i, preturi[i]); // 0 10, apoi 1 15, apoi 2 8.
}

for (const pret of preturi) {
  console.log(pret); // 10, apoi 15, apoi 8.
}

În for...of primim direct fiecare element. const pret este creat pentru fiecare repetare, deci îl putem folosi fără reatribuire.

function sumaPreturilor(preturi) {
  let total = 0;
  for (const pret of preturi) {
    total += pret;
  }
  return total;
}

console.log(sumaPreturilor([10, 15, 8])); // 33
console.log(sumaPreturilor([]));         // 0

Recapitulare: for grupează contorul, condiția și actualizarea; while verifică înaintea fiecărei repetări; do...while verifică după, deci execută blocul cel puțin o dată.

8. map, filter și forEach: trei întrebări diferite

Aceste metode primesc un callback și îl aplică elementelor listei.

const preturi = [10, 15, 8];

const duble = preturi.map(pret => pret * 2);
console.log(duble); // [20, 30, 16]

const accesibile = preturi.filter(pret => pret <= 10);
console.log(accesibile); // [10, 8]

preturi.forEach(pret => console.log(`${pret} lei`));
// Afișează 10 lei, 15 lei, 8 lei, pe linii separate.

console.log(preturi); // [10, 15, 8]: aceste callbackuri nu au modificat lista.
  • map: „Ce valoare nouă obțin pentru fiecare element?” Returnează o listă nouă.
  • filter: „Ce elemente respectă condiția?” Returnează o listă nouă cu cele păstrate.
  • forEach: „Ce acțiune fac pentru fiecare element?” Nu construiește o listă rezultat; returnează undefined.

În filter, callbackul nostru returnează true pentru elementele păstrate. Metoda nu șterge elemente din lista inițială.

Încă cinci metode de recunoscut 
const preturi = [10, 15, 8];
console.log(preturi.find(pret => pret > 10));  // 15: primul găsit.
console.log(preturi.some(pret => pret > 10));  // true: există cel puțin unul.
console.log(preturi.every(pret => pret > 10)); // false: nu sunt toate.
console.log(preturi.indexOf(8));              // 2: indexul valorii.
console.log(preturi.indexOf(99));             // -1: valoare absentă.

const total = preturi.reduce((suma, pret) => suma + pret, 0);
console.log(total); // 33

reduce adună într-un singur rezultat: pornește cu suma = 0, apoi calculează 10, 25 și 33. Nu trebuie să memorezi toate metodele acum; problemele pot fi rezolvate cu bucle simple.

9. Obiectele: date care au legătură între ele

Un obiect literal folosește acolade și perechi cheie: valoare. Putem avea și obiecte în interiorul altor obiecte.

const cafenea = {
  nume: "Cafea și cod",
  "locuri-libere": 8,
  adresa: { oras: "Iași", strada: "Florilor" }
};

console.log(cafenea.nume);             // "Cafea și cod"
console.log(cafenea["locuri-libere"]); // 8
console.log(cafenea.adresa.oras);      // "Iași"

const proprietate = "nume";
console.log(cafenea[proprietate]);     // "Cafea și cod"
cafenea["locuri-libere"] = 6;

Punctul este potrivit pentru nume simple. Parantezele drepte sunt utile pentru o cheie cu cratimă sau pentru o cheie păstrată într-o variabilă. cafenea.proprietate ar căuta chiar cheia „proprietate”.

10. O funcție dintr-un obiect se numește metodă

const comanda = {
  produs: "Latte",
  pret: 15,
  cantitate: 2,
  calculeazaTotal() {
    return this.pret * this.cantitate;
  }
};

console.log(comanda.produs);           // "Latte": citim o proprietate.
console.log(comanda.calculeazaTotal()); // 30: apelăm o metodă.

În apelul comanda.calculeazaTotal(), this este obiectul comanda. Astfel, metoda citește prețul și cantitatea acelui obiect.

Forma calculeazaTotal() { ... } este o scriere scurtă a unei metode. Pentru acest exemplu am putea scrie și calculeazaTotal: function () { ... }.

this depinde de modul de apelare. Pentru început, apelează metoda prin obiect, ca mai sus. O funcție arrow preia this din contextul exterior, deci nu o folosim aici în locul metodei.

11. Atelier: cum lucrăm la cele 34 de probleme

  1. Citește cerința și identifică datele de intrare.
  2. Scrie pașii în cuvinte: „pornesc cu zero, parcurg lista, adun”.
  3. Transformă pașii într-o funcție și apeleaz-o cu exemplele date.
  4. Testează și un caz diferit: zero, numere negative, valori egale sau listă goală, unde au sens.
  5. Abia apoi deschide rezolvarea și compară ideile.

Folosește un fișier exercitii.js, încărcat într-un HTML cu <script src="exercitii.js" defer></script>. Vezi rezultatele în DevTools → Console. Rulează câte o rezolvare pe rând; fiecare bloc este complet și independent.

În majoritatea exercițiilor, datele sunt argumentele funcției, iar console.log() afișează rezultatul. La problemele 18 și 23 folosim prompt() pentru citirea repetată de la tastatură până la 0. Dialogurile apar doar când rulezi tu codul copiat.

Unelte mici pe care le întâlnești în soluții

  • Number(text) convertește textul în număr; Number.isSafeInteger(n) verifică un întreg reprezentat exact în intervalul sigur.
  • Math.sqrt(n) calculează rădăcina pătrată; Math.abs(n) dă valoarea absolută.
  • lista.join(" ") transformă lista în text, cu spații între elemente.
  • text.toLowerCase() trece la litere mici; text.trim() elimină spațiile albe de la capete.
  • break oprește bucla; continue sare la următoarea repetare.

Lucrăm cu numere mici, finite, de tipul cerut în enunț. Pentru intervale folosim întregi; la calculele zecimale pot apărea mici aproximări. Soluțiile Fibonacci cu Number limitează numărul de termeni la 79 pentru a păstra rezultate întregi exacte.

La problemele cu litera „a” numărăm atât a, cât și A; ă și â sunt litere diferite. Indicii din texte încep de la 0. Folosim cuvinte obișnuite, fără emoji.

Reține două rezultate corecte: 1 nu este prim; maximul listei [4, 5, 3, 0, -3, 1] este 5. Nivelurile sunt orientative: începe cu primele zece, apoi continuă în ritmul tău.

1. Numărul următor

Primești un număr întreg. Afișează numărul care urmează după el.

Exemple: 3 → 4; -4 → -3.

Vezi rezolvarea și explicația pentru problema 1

Adăugăm 1 și returnăm rezultatul. Funcția poate fi apelată cu orice întreg mic, inclusiv unul negativ.

function urmatorul(numar) {
  return numar + 1;
}
console.log(urmatorul(3));  // 4
console.log(urmatorul(-4)); // -3

2. Opusul unui număr

Primești un număr întreg. Afișează opusul lui.

Exemple: 3 → -3; -4 → 4; 0 → 0.

Vezi rezolvarea și explicația pentru problema 2

Minusul din fața numărului îi schimbă semnul. Tratăm separat zero, ca să afișăm 0 și nu valoarea specială -0 din JavaScript.

function opusul(numar) {
  if (numar === 0) {
    return 0;
  }
  return -numar;
}
console.log(opusul(3));  // -3
console.log(opusul(-4)); // 4
console.log(opusul(0));  // 0

Înapoi la lista acestui nivel ↑

3. Pozitiv, negativ sau nul?

Primești un număr întreg. Afișează dacă este pozitiv, negativ sau nul.

Exemple: 3 → pozitiv; -4 → negativ; 0 → nul.

Vezi rezolvarea și explicația pentru problema 3

Verificăm întâi dacă numărul este peste zero, apoi sub zero. Dacă nu este în niciuna dintre aceste situații, este zero.

function descrieSemnul(numar) {
  if (numar > 0) {
    return "S-a introdus o valoare pozitivă";
  }
  if (numar < 0) {
    return "S-a introdus o valoare negativă";
  }
  return "S-a introdus o valoare nulă";
}
console.log(descrieSemnul(3));  // S-a introdus o valoare pozitivă
console.log(descrieSemnul(-4)); // S-a introdus o valoare negativă
console.log(descrieSemnul(0));  // S-a introdus o valoare nulă

Înapoi la lista acestui nivel ↑

4. Schimb de locuri

Primești două numere. Interschimbă valorile din cele două variabile și afișează-le.

Exemple: 3, 2 → 2, 3; -3, 2 → 2, -3.

Vezi rezolvarea și explicația pentru problema 4

Păstrăm prima valoare într-o variabilă temporară, ca să nu o pierdem. Schimbăm parametrii locali și returnăm valorile în noua ordine; variabilele apelantului nu se modifică automat.

function interschimba(a, b) {
  const temporar = a;
  a = b;
  b = temporar;
  return [a, b];
}
console.log(interschimba(3, 2).join(" "));  // 2 3
console.log(interschimba(-3, 2).join(" ")); // 2 -3

Înapoi la lista acestui nivel ↑

5. Suma și produsul

Primești două numere. Afișează suma și produsul lor.

Exemple: 3, 2 → sumă 5, produs 6; -3, 2 → sumă -1, produs -6; 0, 2 → sumă 2, produs 0.

Vezi rezolvarea și explicația pentru problema 5

Calculăm cele două rezultate și le punem într-un mesaj. Într-un template literal, expresiile dintre ${ și } sunt evaluate.

function sumaSiProdusul(a, b) {
  return `Suma este ${a + b}. Produsul este ${a * b}.`;
}
console.log(sumaSiProdusul(3, 2));
// Suma este 5. Produsul este 6.
console.log(sumaSiProdusul(-3, 2));
// Suma este -1. Produsul este -6.
console.log(sumaSiProdusul(0, 2));
// Suma este 2. Produsul este 0.

Înapoi la lista acestui nivel ↑

6. Minimul și maximul a două numere

Primești două numere. Afișează valoarea minimă și valoarea maximă.

Exemple: 4, 2 → minim 2, maxim 4; -6, 2 → minim -6, maxim 2.

Vezi rezolvarea și explicația pentru problema 6

Pornim cu prima valoare ca minim și a doua ca maxim. Dacă ordinea este inversă, schimbăm valorile. Pentru două numere egale, minimul și maximul sunt egale.

function minimSiMaxim(a, b) {
  let minim = a;
  let maxim = b;
  if (a > b) {
    minim = b;
    maxim = a;
  }
  return `Valoarea minimă: ${minim}. Valoarea maximă: ${maxim}.`;
}
console.log(minimSiMaxim(4, 2));  // Valoarea minimă: 2. Valoarea maximă: 4.
console.log(minimSiMaxim(-6, 2)); // Valoarea minimă: -6. Valoarea maximă: 2.
console.log(minimSiMaxim(3, 3));  // Valoarea minimă: 3. Valoarea maximă: 3.

Înapoi la lista acestui nivel ↑

7. Din mile în kilometri

Transformă o distanță din mile în kilometri, folosind 1 milă = 1.60934 km. Respinge o distanță negativă.

Exemple: 10 → 16.0934 km; -10 → distanță invalidă.

Vezi rezolvarea și explicația pentru problema 7

Verificăm mai întâi distanța, apoi înmulțim cu factorul de conversie. O distanță de zero este validă.

function mileInKilometri(mile) {
  if (mile < 0) {
    return "Distanță invalidă";
  }
  return `${mile} mile = ${mile * 1.60934} km`;
}
console.log(mileInKilometri(10));  // 10 mile = 16.0934 km
console.log(mileInKilometri(-10)); // Distanță invalidă
console.log(mileInKilometri(0));   // 0 mile = 0 km

Înapoi la lista acestui nivel ↑

8. Împărțirea cu o verificare

Împarte primul număr la al doilea. Dacă împărțitorul este zero, afișează un mesaj de eroare.

Exemple: 4, 2 → 2; -6, 2 → -3; 3, 0 → operație imposibilă.

Vezi rezolvarea și explicația pentru problema 8

Verificarea lui b trebuie făcută înaintea împărțirii. Ieșim din funcție prin return dacă nu putem continua.

function impartire(a, b) {
  if (b === 0) {
    return "Operație imposibilă; împărțitorul este nul";
  }
  return `Rezultatul împărțirii este ${a / b}`;
}
console.log(impartire(4, 2));  // Rezultatul împărțirii este 2
console.log(impartire(-6, 2)); // Rezultatul împărțirii este -3
console.log(impartire(3, 0));  // Operație imposibilă; împărțitorul este nul

Înapoi la lista acestui nivel ↑

9. Viteza medie

Primești distanța în kilometri și durata în ore. Calculează viteza medie. Respinge distanța sau durata negativă și tratează separat durata zero. Distanța zero cu durată pozitivă este validă.

Exemple: 100, 2 → 50 km/oră; 60, 0 → mesaj despre teleportare; -30, 3 sau 30, -3 → date invalide.

Vezi rezolvarea și explicația pentru problema 9

Mai întâi respingem valorile negative, inclusiv situația în care ambele sunt negative. Abia apoi verificăm durata zero. Pentru date valide, viteza este distanță / durată.

function vitezaMedie(distanta, durata) {
  if (distanta < 0 || durata < 0) {
    return "Distanța și durata nu pot fi negative";
  }
  if (durata === 0) {
    return "Felicitări! Se pare că ai inventat teleportarea!";
  }
  return `Viteza medie a fost ${distanta / durata} km/oră`;
}
console.log(vitezaMedie(100, 2));  // Viteza medie a fost 50 km/oră
console.log(vitezaMedie(60, 0));   // Felicitări! Se pare că ai inventat teleportarea!
console.log(vitezaMedie(-30, 3));  // Distanța și durata nu pot fi negative
console.log(vitezaMedie(30, -3));  // Distanța și durata nu pot fi negative
console.log(vitezaMedie(-30, -3)); // Distanța și durata nu pot fi negative

Înapoi la lista acestui nivel ↑

10. Ecuația de gradul I

Primești a și b pentru ecuația a × x + b = 0. Afișează ecuația și soluția. Tratează și cazurile în care a este zero.

Exemple: a = 2, b = 4 → x = -2; a = 0, b = 0 → orice număr real; a = 0, b = 2 → fără soluție.

Vezi rezolvarea și explicația pentru problema 10

11. Ecuația de gradul al II-lea

Primești a, b și c pentru a × x² + b × x + c = 0. Afișează soluțiile reale. Dacă a = 0, rezolvă ecuația rămasă.

Exemple: 2, 1, 2 → fără soluții reale; 2, 4, 2 → -1; 1, 1, -6 → -3 și 2; 0, 0, 0 → orice număr real.

Vezi rezolvarea și explicația pentru problema 11

Dacă a = 0, rămâne ecuația b × x + c = 0. Altfel calculăm delta = b² - 4ac. Delta negativă: fără soluții reale; zero: o soluție; pozitivă: două soluții, (-b ± √delta) / (2a).

function ecuatieGradulDoi(a, b, c) {
  if (a === 0) {
    if (b !== 0) {
      return `Soluție: x = ${-c / b}`;
    }
    if (c === 0) {
      return "Soluție: orice număr real";
    }
    return "Ecuația nu are soluție";
  }

  const delta = b * b - 4 * a * c;
  if (delta < 0) {
    return "Ecuația nu are soluții reale";
  }
  if (delta === 0) {
    return `Soluție: x = ${-b / (2 * a)}`;
  }
  const x1 = (-b - Math.sqrt(delta)) / (2 * a);
  const x2 = (-b + Math.sqrt(delta)) / (2 * a);
  return `Soluții: x1 = ${x1}, x2 = ${x2}`;
}
console.log(ecuatieGradulDoi(2, 1, 2));  // Ecuația nu are soluții reale
console.log(ecuatieGradulDoi(2, 4, 2));  // Soluție: x = -1
console.log(ecuatieGradulDoi(1, 1, -6)); // Soluții: x1 = -3, x2 = 2
console.log(ecuatieGradulDoi(0, 0, 0));  // Soluție: orice număr real
console.log(ecuatieGradulDoi(0, 2, 4));  // Soluție: x = -2
console.log(ecuatieGradulDoi(0, 0, 2));  // Ecuația nu are soluție

26. Minimele locale

Afișează valorile strict mai mici decât vecinii lor. Primul element se compară doar cu al doilea, iar ultimul doar cu penultimul. Pentru o listă cu mai puțin de două elemente, alegem să nu raportăm minime locale.

Vezi rezolvarea și explicația pentru problema 26

Tratăm separat capetele și parcurgem interiorul de la indexul 1 până înainte de ultimul. Folosim comparații stricte: într-o listă [2, 2], niciun element nu este minim local.

function minimeLocale(lista) {
  const rezultat = [];
  if (lista.length < 2) {
    return rezultat;
  }
  if (lista[0] < lista[1]) {
    rezultat.push(lista[0]);
  }
  for (let i = 1; i < lista.length - 1; i++) {
    if (lista[i] < lista[i - 1] && lista[i] < lista[i + 1]) {
      rezultat.push(lista[i]);
    }
  }
  const ultimul = lista.length - 1;
  if (lista[ultimul] < lista[ultimul - 1]) {
    rezultat.push(lista[ultimul]);
  }
  return rezultat;
}

function subMedie(lista) {
  if (lista.length === 0) {
    return [];
  }
  let suma = 0;
  for (const numar of lista) {
    suma += numar;
  }
  const media = suma / lista.length;
  const rezultat = [];
  for (const numar of lista) {
    if (numar < media) {
      rezultat.push(numar);
    }
  }
  return rezultat;
}
console.log(subMedie([4, 0, 7, -3, 3, 1])); // [0, -3, 1]
console.log(subMedie([2, 2]));              // []
console.log(subMedie([]));                  // []

30. De câte ori apare „a”?

Primești un text. Numără aparițiile literei „a”, fără diferență între a și A.

Exemple: „Ana are mere” → 3.

Vezi rezolvarea și explicația pentru problema 30

Transformăm textul în litere mici și creștem un contor pentru fiecare a. Un text fără această literă, inclusiv textul gol, produce zero.

function numaraA(text) {

31. Pe ce poziții apare „a”?

Primești un text. Afișează indicii literei „a”, ignorând diferența dintre a și A. Numerotarea începe de la zero.

Exemple: „programare” → 5, 7; „algoritmica” → 0, 10.

Vezi rezolvarea și explicația pentru problema 31

Avem nevoie de index, deci folosim for cu un contor. Când găsim litera, păstrăm indexul, nu caracterul.

function pozitiiA(text) {
  const rezultat = [];
  for (let i = 0; i < text.length; i++) {
    if (text[i].toLowerCase() === "a") {
      rezultat.push(i);
    }
  }
  return rezultat;
}
console.log(pozitiiA("programare"));  // [5, 7]
console.log(pozitiiA("algoritmica")); // [0, 10]
console.log(pozitiiA("Ana"));         // [0, 2]
console.log(pozitiiA("mere"));        // []

32. Câte cuvinte are propoziția?

Numără cuvintele dintr-un text. În acest exercițiu, un cuvânt este un grup de caractere separat de spații albe: spațiu, tab sau linie nouă. Spațiile consecutive nu adaugă cuvinte.

Exemple: „Imi place sa fac programare” → 5; „Vreau sa fiu programator!” → 4; text gol → 0.

Vezi rezolvarea și explicația pentru problema 32

Urmărim dacă suntem deja în interiorul unui cuvânt. Numărăm doar trecerea de la spațiu alb la un caracter. caracter.trim() === "" recunoaște spațiile albe. Punctuația lipită rămâne parte din cuvânt; nu facem analiză lingvistică.

function numaraCuvinte(text) {
  let total = 0;
  let inCuvant = false;
  for (const caracter of text) {
    if (caracter.trim() === "") {
      inCuvant = false;
    } else if (!inCuvant) {
      total++;
      inCuvant = true;
    }
  }
  return total;
}
console.log(numaraCuvinte("Imi place sa fac programare")); // 5
console.log(numaraCuvinte("Vreau sa fiu programator!"));    // 4
console.log(numaraCuvinte("  Ana   are mere  "));          // 3
console.log(numaraCuvinte(""));                           // 0

33. Procentajul de vocale

Calculează procentajul vocalelor dintr-un text, ignorând spațiile albe la numărul total de caractere. Considerăm vocale a, e, i, o, u, ă, â, î, indiferent de majuscule. Celelalte caractere, inclusiv punctuația, intră în total.

Exemple: „Ana are mere” → 6 vocale din 10 caractere fără spații → 60%.

Vezi rezolvarea și explicația pentru problema 33

Numărăm separat vocalele și toate caracterele care nu sunt spații albe. Procentajul este vocale / caractere × 100. Pentru text gol sau doar spații alegem 0%, ca să evităm împărțirea la zero.

function procentVocale(text) {
  const vocale = "aeiouăâî";
  let totalCaractere = 0;
  let totalVocale = 0;
  for (const caracter of text.toLowerCase()) {
    if (caracter.trim() === "") {
      continue;
    }
    totalCaractere++;
    if (vocale.includes(caracter)) {
      totalVocale++;
    }
  }
  if (totalCaractere === 0) {
    return 0;
  }
  return totalVocale / totalCaractere * 100;
}
console.log(`${procentVocale("Ana are mere")}%`); // 60%
console.log(`${procentVocale("ĂÂÎ")}%`);          // 100%
console.log(`${procentVocale("   ")}%`);          // 0%
// includes() verifică dacă textul conține caracterul căutat.

34. Litera „a” într-o listă de texte

Primești o listă de stringuri. Numără toate aparițiile literei „a” sau „A” din toate textele.

Exemple: ["Ana", "are", "mere"] → 3.

Vezi rezolvarea și explicația pentru problema 34

Reutilizăm o funcție care numără litera într-un text. Funcția principală parcurge lista și adună rezultatele. Acesta este avantajul funcțiilor: împărțim o problemă în acțiuni mici.

function numaraA(text) {
  let total = 0;
  for (const caracter of text.toLowerCase()) {
    if (caracter === "a") {
      total++;
    }
  }
  return total;
}
function numaraAInLista(texte) {
  let total = 0;
  for (const text of texte) {
    total += numaraA(text);
  }
  return total;
}
console.log(numaraAInLista(["Ana", "are", "mere"])); // 3
console.log(numaraAInLista(["A", "a", "cafea"]));   // 4
console.log(numaraAInLista([]));                     // 0
