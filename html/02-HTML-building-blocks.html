02 - Elementele de bază HTML

O introducere simplă în structura elementelor HTML.

1. Ce este HTML?

HTML vine de la HyperText Markup Language și descrie structura unei pagini web.

  • HyperText - paginile pot fi legate prin linkuri;
  • Markup - folosim etichete pentru a descrie conținutul;
  • Language - HTML are reguli și o sintaxă proprie.

<h1>Prima mea pagină</h1>

2. HTML, CSS și JavaScript

Cele trei tehnologii au roluri diferite și lucrează împreună.

HTML
Structura și conținutul
CSS
Culorile și aspectul
JavaScript
Comportamentul și interacțiunile

Exemplu: HTML creează un buton, CSS îl colorează, iar JavaScript îi spune ce să facă atunci când este apăsat.

3. Caracteristicile HTML

  • HTML este un limbaj de marcare, nu un limbaj de programare.
  • Browserul citește HTML și afișează pagina.
  • HTML descrie ce reprezintă elementele: titlu, paragraf, imagine sau link.
  • Versiunea modernă folosită astăzi este HTML5.
  • HTML nu diferențiază literele mari de cele mici în numele etichetelor, dar folosim litere mici pentru consecvență.

5. Din ce este format un element HTML?

Un element HTML conține, de obicei:

  • o etichetă de deschidere;
  • conținutul elementului;
  • o etichetă de închidere.
<p> Acesta este un paragraf </p>

<p>Acesta este un paragraf.</p>

6. Elementele pot fi imbricate

Un element poate fi pus în interiorul altui element.

<p>Învățăm <strong>HTML</strong> împreună.</p>

Rezultatul din browser:

Învățăm HTML împreună.

Elemente fără conținut

Unele elemente folosesc o singură etichetă, de exemplu o imagine:

<img src="logo.jpg" alt="Logo" />

7. Elemente block și inline

Elemente block

Încep pe un rând nou și ocupă spațiul disponibil.

Exemple: <p>, <h1>, <div>.

Elemente inline

Rămân în interiorul rândului și ocupă doar spațiul necesar. Exemple: <strong>, <em>, <a>.

Acesta este un paragraf cu text îngroșat și text înclinat.

8. Atribute HTML

Atributele oferă informații suplimentare despre un element.

  • se scriu în eticheta de deschidere;
  • conțin un nume și o valoare;
  • valoarea este scrisă între ghilimele.

<img src="logo.jpg" alt="Logo-ul site-ului" />

În exemplu, src și alt sunt atribute, iar textele dintre ghilimele sunt valorile lor.

9. Spații și comentarii

Browserul reduce mai multe spații și treceri pe rând nou la un singur spațiu atunci când afișează textul.

  • Folosește spații și rânduri noi pentru un cod ușor de citit.
  • Scrie elementele block pe rânduri separate.
  • Indentează elementele aflate în interiorul altor elemente.

Comentarii

Comentariile sunt vizibile în cod, dar nu sunt afișate în pagină.

<!-- Acesta este un comentariu -->

10. Structura unui document HTML

Fiecare pagină HTML pornește de la o structură de bază.

<!doctype html>
<html lang="ro">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Titlul paginii</title>
  </head>
  <body>
    Conținutul vizibil
  </body>
</html>
  • <!doctype html> anunță că documentul folosește HTML modern;
  • <html> cuprinde întreaga pagină;
  • <head> conține informații pentru browser;
  • <body> conține elementele vizibile în pagină.

Ce putem pune în head?

<title>Titlul filei din browser</title>
<meta name="description" content="Descrierea paginii" />
<link rel="stylesheet" href="styles.css" />
<script src="script.js" defer></script>

15. Structura semantică a paginii

Aceste elemente explică rolul fiecărei zone:

  • <header> — partea de început;
  • <nav> — navigația;
  • <main> — conținutul principal;
  • <section> — o secțiune;
  • <article> — conținut independent;
  • <aside> — conținut secundar;
  • <footer> — partea de final.
<header> - titlu și introducere
<nav> - linkuri de navigare
<main> - conținutul principal
<aside> - informații secundare
<footer> - finalul paginii

25. Afișarea unei pagini cu iframe

<iframe> poate afișa o altă pagină în interiorul paginii curente. Nu toate site-urile permit acest lucru.

<iframe src="index.html" title="Pagina principală"></iframe>

26. Accesibilitate de bază

O pagină bună trebuie să poată fi folosită de cât mai multe persoane.

  • Folosește titlurile în ordine: h1, apoi h2 și h3.
  • Scrie un atribut alt util pentru imaginile importante.
  • Asociază fiecare câmp de formular cu un <label>.
  • Folosește elementul <button> pentru acțiuni.
  • Verifică dacă pagina poate fi parcursă cu tasta Tab.
  • Nu folosi valori pozitive pentru tabindex; păstrează ordinea naturală.

<img src="pisica.jpg" alt="O pisică neagră pe un scaun" />

27. Reguli simple și greșeli frecvente

  • Închide elementele care au etichetă de închidere.
  • Imbrică elementele în ordinea corectă.
  • Scrie valorile atributelor între ghilimele.
  • Folosește litere mici și o indentare consecventă.
  • Preferă elementele semantice în loc de <div> când au sens.
  • Nu folosi elemente vechi precum <font> și <center>.

Corect: <p>Text <strong>important</strong></p>

29. Mini-exercițiu: pagina unui mic festival

Creează un fișier numit festival.html pentru prezentarea unui festival imaginar de muzică, film, gastronomie sau tehnologie.

Cerințe

  1. Adaugă un <header> cu numele festivalului, perioada și o scurtă descriere.
  2. Creează un <nav> cu linkuri interne către secțiunile Despre, Program și Contact.
  3. În secțiunea Despre, adaugă o imagine cu atributele src, alt, width și height.
  4. Adaugă o listă neordonată cu minimum trei activități disponibile.
  5. Creează un tabel cu trei coloane: Ora, Activitatea și Locul. Adaugă minimum trei rânduri.
  6. Folosește <details> și <summary> pentru a ascunde și afișa regulile festivalului.
  7. În secțiunea Contact, adaugă un link către o adresă de e-mail și un link către un număr de telefon.
  8. Încheie pagina cu un <footer> care conține anul și numele festivalului.

Structură orientativă

<header>
  <h1>Numele festivalului</h1>
  <nav>... linkuri interne ...</nav>
</header>

<main>
  <section id="despre">...</section>
  <section id="program">...</section>
  <section id="contact">...</section>
</main>

<footer>...</footer>

Bonus

Folosește <mark> pentru activitatea recomandată și colspan pentru un rând din tabel care anunță o pauză.
