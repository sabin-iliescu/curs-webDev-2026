HTML + CSS + JavaScript

Un demo simplu care arată rolul și legătura dintre cele trei limbaje.

1. HTML creează structura

HTML adaugă în pagină titluri, paragrafe, butoane, imagini și alte elemente.

  • HTML = structura;
  • CSS = aspectul;
  • JavaScript = comportamentul.

2. CSS poate fi adăugat în trei moduri

CSS inline

Acest element este stilizat direct cu atributul style.

CSS intern

Acest element este stilizat de regulile din <style>.

CSS extern

Acest element este stilizat din fișierul styles.css.

3. JavaScript inline

Apasă butonul pentru a modifica acest text.

Codul JavaScript este scris direct în atributul onclick.

4. JavaScript în elementul script

Acest mesaj își va schimba aspectul.

Butonul este conectat la codul din <script>, aflat la finalul acestei pagini HTML.

5. JavaScript dintr-un fișier extern

Sunt o cutie simplă.

Număr de clickuri: 0

Acest comportament este definit în fișierul script.js.

6. Flow-ul complet

  1. Browserul citește index.html și creează structura.
  2. HTML încarcă styles.css și aplică aspectul.
  3. HTML încarcă script.js și activează interacțiunile.
  4. Utilizatorul apasă un buton.
  5. JavaScript modifică un element HTML sau o clasă CSS.
