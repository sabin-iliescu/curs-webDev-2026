05 - CSS Properties

Proprietăți CSS uzuale, explicate prin exemple vizibile și simple.

1. Ce este o proprietate CSS?

Proprietatea spune ce aspect vrem să modificăm, iar valoarea spune cum.

p {
  color: blue;
  font-size: 18px;
}

Sintaxa și selectorii sunt explicați în lecția 04 - CSS Basics.

2. Font family

font-family stabilește familia fontului.

body {
  font-family: Arial, Helvetica, sans-serif;
}

Scriem mai multe variante. Dacă primul font nu există, browserul încearcă următorul.

3. Dimensiunea fontului

font-size controlează dimensiunea textului.

UnitateExplicație

remRaportată la dimensiunea de bază a paginii
 
h1 { font-size: 2rem; }
p { font-size: 18px; }

4. Stilul textului

  • font-style - text normal sau italic;
  • font-weight - grosimea textului;
  • text-transform - litere mari, mici sau capitale;
  • text-decoration - subliniere sau tăiere.

Exemplu de text formatat

.text {
  font-style: italic;
  font-weight: 700;
  text-transform: uppercase;
  text-decoration: underline;
}

5. Așezarea textului

  • text-align - alinierea textului;
  • line-height - spațiul dintre rânduri;
  • letter-spacing - spațiul dintre litere;
  • word-spacing - spațiul dintre cuvinte;
  • overflow-wrap - permite ruperea cuvintelor foarte lungi.

Acest paragraf are textul centrat și spații mai mari între rânduri, litere și cuvinte.

6. Text prea lung

text-overflow: ellipsis afișează trei puncte când textul nu încape.

Acesta este un text foarte lung care nu încape în cutia sa.

.text-lung {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

7. Umbra textului

text-shadow primește deplasarea orizontală, deplasarea verticală, blurul și culoarea.

Text cu umbră

h2 {
  text-shadow: 2px 2px 5px #999;
}

8. Culori și transparență

color schimbă textul, iar background-color schimbă fundalul.

color: red;
color: #ff0000;
color: rgb(255, 0, 0);
color: hsl(0, 100%, 50%);

Text alb pe un fundal mov.

Fundal albastru cu transparență.

rgba() face transparentă doar culoarea. opacity face transparent întregul element, inclusiv copiii lui.

9. Imagini de fundal

.hero {
  background-color: lightblue;
  background-image: url("fundal.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}
  • Folosește <img> pentru o imagine importantă pentru conținut.
  • Folosește background-image pentru o imagine decorativă.

10. Gradient

Un gradient este creat de browser și nu necesită un fișier imagine.

Fundal cu gradient
.banner {
  background: linear-gradient(135deg, purple, blue);
}

11. Box model - recapitulare

Fiecare element HTML este o cutie formată din:

  1. content;
  2. padding;
  3. border;
  4. margin.
Conținutul cutiei

box-sizing: border-box include paddingul și bordura în lățimea stabilită.

12. Width și height

  • width și height stabilesc dimensiunea;
  • min-width și min-height stabilesc minimul;
  • max-width și max-height stabilesc maximul.
Lățime 80%, dar maximum 420px.

max-width este foarte util pentru pagini responsive.

13. Margin și padding

margin creează spațiu în exterior, iar padding în interior.

.cutie {
  margin: 20px;
  padding: 10px 20px;
}

În padding: 10px 20px, valoarea 10px este verticală, iar 20px este orizontală.

14. Border și border-radius

Cutie cu bordură punctată și colțuri rotunjite.
.cutie {
  border: 3px dashed red;
  border-radius: 16px;
}

15. Marginile verticale se pot uni

Uneori marginile de sus și de jos ale elementelor block se combină. Browserul păstrează, de obicei, marginea mai mare.

Pentru început este suficient să știi că două margini verticale nu se adună întotdeauna.

16. Display

  • block - elementul începe pe rând nou;
  • inline - elementul rămâne în rând;
  • inline-block - rămâne în rând, dar acceptă dimensiuni;
  • none - elementul este eliminat din afișare;
  • flex - așază mai ușor elementele într-un rând sau coloană.

18. Position

Părinte cu position: relative Copil absolute

19. Z-index

z-index controlează ordinea elementelor suprapuse.

z-index: 1
z-index: 2

Valoarea mai mare apare deasupra. z-index funcționează în contexte de suprapunere și, de obicei, cu elemente poziționate.

20. Display none și visibility hidden

  • display: none ascunde elementul și elimină spațiul ocupat;
  • visibility: hidden ascunde elementul, dar păstrează spațiul.

21. Verificarea proprietăților în DevTools

  1. Deschide pagina în Chrome.
  2. Inspectează una dintre demonstrații.
  3. Debifează padding, border sau background.
  4. Modifică valoarea direct în panoul Styles.
  5. Observă diagrama Box Model din panoul Computed.

22. Mini-exercițiu

Creează un card de profil folosind HTML și CSS.

  1. Adaugă o imagine, un titlu, o descriere și un link.
  2. Setează familia și dimensiunea fontului.
  3. Adaugă fundal, padding, border și colțuri rotunjite.
  4. Limitează cardul cu max-width.
  5. Transformă linkul într-un buton și adaugă o stare :hover.

23. Exercițiu puțin mai complex

Creează o secțiune cu trei carduri pentru un mic eveniment.

  1. Așază cardurile cu display: flex.
  2. Folosește gap pentru spațiul dintre ele.
  3. Permite trecerea pe rând nou cu flex-wrap.
  4. Adaugă câte un fundal sau gradient fiecărui card.
  5. Folosește aceleași valori pentru padding, border și border-radius.
  6. Adaugă o etichetă poziționată absolute pe cardul recomandat.
  7. Verifică pagina la o fereastră îngustă.

24. Recapitulare

  • Proprietățile controlează aspectul elementelor.
  • Textul are proprietăți pentru font și așezare.
  • Fundalurile pot folosi culori, imagini sau gradiente.
  • Box model explică dimensiunile și spațiile.
  • display, Flexbox și position controlează așezarea.
  • DevTools ne ajută să testăm rapid proprietățile.
