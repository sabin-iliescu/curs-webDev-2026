08 - Layouting

Cum așezăm elementele într-o pagină, pas cu pas.

1. Ce este un layout?

Un layout este modul în care așezăm elementele unei pagini: meniul sus, conținutul în centru și alte informații alături.

Putem privi pagina ca pe un grup de cutii, unele în interiorul altora.

Antet (header)
Meniu (nav)
Articol (article)
Bară laterală (aside)
Subsol (footer)

2. Împărțim pagina în bucăți mici

Înainte să scriem CSS, ne uităm la model și identificăm părțile lui.

  1. Găsim zonele mari: antet, conținut și subsol.
  2. Împărțim fiecare zonă: antetul poate avea logo, meniu și contact.
  3. Alegem elementele HTML potrivite pentru fiecare parte.
  4. Decidem ce stă pe un rând și ce stă unul sub altul.

Lucrăm de la mare la mic. Așezăm mai întâi zonele paginii, apoi elementele din interiorul lor.

3. Începem cu structura HTML

  • header este antetul.
  • nav grupează linkurile de navigare.
  • main conține partea principală a paginii.
  • article conține un material care are sens și singur.
  • aside conține informații suplimentare.
  • footer este subsolul.

Într-o pagină separată, structura poate arăta așa:

<header>Site-ul meu</header>
<nav>Linkuri de navigare</nav>

<main class="continut-demo">
  <article class="articol-demo">
    <h1>Prima mea pagină</h1>
    <p>Aici scriu conținutul principal.</p>
  </article>

  <aside class="lateral-demo">
    <h2>De reținut</h2>
    <p>Aici adaug informații suplimentare.</p>
  </aside>
</main>

<footer>Realizat de mine</footer>

HTML descrie rolul elementelor. CSS stabilește cum sunt așezate. Un aside nu apare automat în dreapta.

4. Block, inline și inline-block

Proprietatea display schimbă felul în care un element ocupă spațiul.

Block

În așezarea normală, începe pe un rând nou și ocupă lățimea disponibilă.

Cutia 1 Cutia 2

Inline

Curge odată cu textul. Pentru un element de text, precum span, width și height nu se aplică.

Text înainte Cutia 1 Cutia 2 text după.

Inline-block

Poate sta lângă alte elemente și acceptă lățime și înălțime.

Cutia 1 Cutia 2 
.block-demo span {
  display: block;
}

.inline-demo span {
  display: inline;
}

.inline-block-demo span {
  display: inline-block;
  width: 120px;
}

5. Centrăm containerul

Containerul este cutia care ține conținutul la un loc. Îi dăm o lățime maximă și margini automate în stânga și în dreapta. 

.pagina-demo {
  max-width: 700px;
  margin: 0 auto;
  padding: 16px;
}
  • max-width limitează lățimea, dar permite micșorarea.
  • margin: 0 auto centrează containerul pe orizontală.
  • padding lasă spațiu în interiorul cutiei.

Folosim și această regulă pentru a calcula mai ușor dimensiunile:

* {
  box-sizing: border-box;
}

Astfel, lățimea declarată include paddingul și bordura.

6. Punem logo-ul și meniul pe un rând

Antetul este părintele. Logo-ul și meniul sunt copiii lui direcți. Aplicăm Flexbox pe părinte. 

<header class="antet-demo">
  <a href="index.html">Site-ul meu</a>
  <nav aria-label="Meniul exemplului">
    <ul class="meniu-demo">
      <li><a href="index.html">Acasă</a></li>
      <li><a href="07-CSS-flexbox.html">Flexbox</a></li>
    </ul>
  </nav>
</header>
.antet-demo {
  display: flex;
  justify-content: space-between;
  align-items: center;
  flex-wrap: wrap;
  gap: 16px;
}

.meniu-demo {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
  list-style: none;
  margin: 0;
  padding: 0;
}

Avem două containere flex: antetul așază logo-ul și meniul, iar lista așază linkurile din meniu. Fiecare părinte își organizează copiii direcți.

7. Facem două coloane

Punem articolul și bara laterală în același container. Articolul primește mai mult spațiu. 

.continut-demo {
  display: flex;
  gap: 16px;
  margin: 16px 0;
}

.articol-demo {
  flex: 2;
  min-width: 0;
}

.lateral-demo {
  flex: 1;
  min-width: 0;
}

flex: 2 și flex: 1 împart lățimea disponibilă pentru coloane în raport de aproximativ 2 la 1. min-width: 0 le permite să se micșoreze, iar gap le separă.

8. Adaptăm pagina pentru telefon

Pe un ecran îngust, coloanele devin prea mici. Cu o regulă @media, le așezăm una sub alta. 

@media (max-width: 600px) {
  .continut-demo {
    flex-direction: column;
  }
}

Regula se aplică atunci când lățimea ferestrei este de cel mult 600px. Micșorează fereastra browserului și urmărește exemplul de mai jos.

10. Temă simplă: pagina mea de prezentare

Creează o pagină despre tine, un hobby sau un loc preferat. Folosește HTML și CSS și pornește de la ideile din lecție.

  1. Creează fișierele prezentare.html și prezentare.css și leagă CSS-ul în <head>.
  2. Adaugă un header cu numele paginii și un nav cu linkuri către două secțiuni: Despre și Contact.
  3. Așază numele și meniul pe același rând cu Flexbox. Folosește gap și flex-wrap.
  4. În main, adaugă cele două secțiuni, una sub alta, fiecare cu un titlu și un paragraf.
  5. Centrează conținutul cu max-width: 800px și margin: 0 auto. Adaugă padding ca textul să nu atingă marginile.
  6. Încheie cu un footer care conține numele tău și un link „Înapoi sus”.

Verifică: linkurile duc la secțiunile potrivite, iar la 375px meniul poate trece pe rând nou fără să iasă din pagină.

11. Temă puțin mai complexă: un mini-blog

Creează fișierele mini-blog.html și mini-blog.css pentru un blog despre călătorii, jocuri sau mâncare.

  1. Desenează pe hârtie zonele mari: antet, conținut, bară laterală și subsol.
  2. Leagă fișierul CSS și creează un antet cu numele blogului și trei linkuri interne: Articol, Despre autor și Contact.
  3. În main, adaugă un article și un aside, așezate pe un rând cu Flexbox.
  4. Articolul să aibă un titlu, două paragrafe și o secțiune cu trei recomandări.
  5. În bara laterală, scrie câteva cuvinte despre autor și adaugă o listă cu trei subiecte ale blogului.
  6. Dă articolului flex: 2, barei laterale flex: 1 și containerului gap: 16px.
  7. La cel mult 600px, așază articolul și bara laterală unul sub altul cu flex-direction: column.
  8. Adaugă datele de contact în subsol, spațiere între zone și culori diferite pentru articol și bara laterală.

Verifică la 375px și la 1100px: pe ecranul mic ai o coloană, iar pe ecranul mare articolul și bara laterală stau alături. Toate linkurile din meniu trebuie să funcționeze.
