1. Un obiect ține lucrurile împreună

O sală are un nume, o capacitate și un număr de locuri ocupate. Le grupăm într-un obiect. Datele sunt proprietăți; o funcție folosită ca proprietate este o metodă.

const sala = {
  nume: "Orion",
  capacitate: 4,
  ocupate: 0,

  rezerva() {
    if (this.ocupate === this.capacitate) return false;
    this.ocupate++;
    return true;
  }
};

console.log(sala.nume);      // "Orion"
console.log(sala.rezerva()); // true
console.log(sala.ocupate);   // 1

sala.rezerva() schimbă starea sălii. În acest apel, this este obiectul sala. Metoda întoarce true dacă a rezervat un loc și false dacă sala este plină.

Forma cu acolade se numește object literal. Putem crea astfel un obiect fără să definim o clasă.

2. Citim și modificăm proprietăți

const film = { titlu: "Aventura pe Lună", durata: 90 };

console.log(film.titlu);      // "Aventura pe Lună"
console.log(film["durata"]);  // 90

const camp = "titlu";
console.log(film[camp]);      // "Aventura pe Lună"

film.durata = 95;             // Modificăm o proprietate.
film.gen = "animație";        // Adăugăm una nouă.
console.log(film.regizor);    // undefined: proprietatea lipsește.

Folosim punctul când știm numele proprietății. Folosim parantezele drepte când numele vine dintr-o variabilă. film.camp ar căuta chiar proprietatea numită „camp”.

Chei, valori și perechi

const film = { titlu: "Aventura pe Lună", durata: 90 };

console.log(Object.keys(film));   // ["titlu", "durata"]
console.log(Object.values(film)); // ["Aventura pe Lună", 90]

for (const [cheie, valoare] of Object.entries(film)) {
  console.log(cheie, valoare);
}
// titlu Aventura pe Lună
// durata 90

Aceste metode întorc array-uri. Ele citesc proprietățile proprii, enumerabile, cu chei de tip string, precum cele din obiectul de mai sus.

De ce putem modifica un obiect declarat cu const? 
const film = { titlu: "Aventura pe Lună" };
const acelasiFilm = film;
acelasiFilm.titlu = "Vacanță pe Marte";

console.log(film.titlu); // "Vacanță pe Marte"
// film = {};           // Eroare: nu putem reatribui variabila const.

const păstrează legătura variabilei cu obiectul. Nu îngheață proprietățile. Atribuirea acelasiFilm = film nu copiază obiectul: ambele variabile se referă la același obiect.

3. O clasă, mai multe obiecte

Când avem mai multe săli cu aceleași reguli, putem folosi o clasă. Constructorul primește datele de pornire, iar new creează o instanță: un obiect construit folosind clasa.

class Sala {
  constructor(nume, capacitate) {
    this.nume = nume;
    this.capacitate = capacitate;
    this.ocupate = 0;
  }

  rezerva() {
    if (this.ocupate === this.capacitate) return false;
    this.ocupate++;
    return true;
  }
}

const orion = new Sala("Orion", 4);
const luna = new Sala("Luna", 6);

orion.rezerva();
console.log(orion.ocupate); // 1
console.log(luna.ocupate);  // 0
console.log(orion === luna); // false: două obiecte diferite.

La new Sala("Orion", 4), JavaScript creează un obiect, îi leagă prototipul de Sala.prototype și execută constructorul cu this legat de noul obiect. Constructorul nostru inițializează proprietățile.

Fiecare sală are propriul număr de locuri ocupate. Rezervarea din Orion nu schimbă sala Luna.

Opțional: o funcție care creează obiecte (factory) 
function creeazaSala(nume, capacitate) {
  return {
    nume,
    capacitate,
    ocupate: 0,
    rezerva() {
      if (this.ocupate === this.capacitate) return false;
      this.ocupate++;
      return true;
    }
  };
}

const sala = creeazaSala("Orion", 4);
sala.rezerva();
console.log(sala.ocupate); // 1

O funcție factory întoarce un obiect și se apelează fără new. Este o altă variantă simplă de a crea obiecte asemănătoare.

4. this: obiectul pe care apelăm metoda

Pentru o metodă obișnuită, contează felul în care o apelăm. În obiect.metoda(), this este obiectul din stânga punctului.

const sala = {
  nume: "Orion",
  prezinta() {
    return `Sala ${this.nume}`;
  }
};

const altaSala = { nume: "Luna", prezinta: sala.prezinta };
console.log(sala.prezinta());     // "Sala Orion"
console.log(altaSala.prezinta()); // "Sala Luna"

Într-un event listener, păstrăm apelul metodei într-un callback:

// Presupunem că avem un buton și o instanță Sala.
buton.addEventListener("click", () => {
  sala.rezerva();
});

Astfel, rezervarea este apelată pe sala. Dacă am transmite direct sala.rezerva către listener, am desprinde metoda de obiectul ei.

Opțional: call și apply aleg explicit valoarea lui this 
function prezinta(prefix, sufix) {
  return prefix + this.nume + sufix;
}

const sala = { nume: "Orion" };
console.log(prezinta.call(sala, "Sala ", "!"));
console.log(prezinta.apply(sala, ["Sala ", "!"]));
// Ambele afișează "Sala Orion!".

call primește argumentele separat; apply le primește într-un array. Funcțiile arrow preiau this din contextul în care sunt create; call și apply nu îl schimbă pentru ele.

5. Unde sunt metodele? Pe prototip

Refolosim clasa Sala din secțiunea 3. Proprietățile create în constructor sunt pe fiecare instanță. Metoda rezerva este pe Sala.prototype și este partajată.

// Rulează după definiția clasei Sala din secțiunea 3.
const prima = new Sala("Orion", 4);
const aDoua = new Sala("Luna", 6);

console.log(Object.keys(prima));
// ["nume", "capacitate", "ocupate"]
console.log(Object.getPrototypeOf(prima) === Sala.prototype); // true
console.log(prima.rezerva === aDoua.rezerva);                 // true

Când citim o proprietate, JavaScript o caută întâi pe obiect, apoi de-a lungul lanțului de prototipuri:

  1. prima — aici găsim nume, capacitate, ocupate
  2. Sala.prototype — aici găsim rezerva
  3. Object.prototype — metode comune, precum toString
  4. null — sfârșitul lanțului

Dacă nu găsește proprietatea nicăieri, rezultatul citirii este undefined.

Opțional: constructori clasici și Object.create

Poți întâlni și funcții constructor în cod mai vechi:

function SalaClasica(nume) {
  this.nume = nume;
}

SalaClasica.prototype.prezinta = function () {
  return `Sala ${this.nume}`;
};

const sala = new SalaClasica("Orion");
console.log(sala.prezinta()); // "Sala Orion"

Object.create creează direct un obiect cu prototipul ales, fără să apeleze un constructor:

const comportament = {
  prezinta() { return `Sala ${this.nume}`; }
};
const sala = Object.create(comportament);
sala.nume = "Luna";
console.log(sala.prezinta()); // "Sala Luna"
console.log(Object.getPrototypeOf(sala) === comportament); // true

Detalii: MDN: prototipuri și moștenire.

6. OOP: obiectul își gestionează starea

OOP înseamnă Object-Oriented Programming, adică programare orientată pe obiecte. Grupăm starea și operațiile în obiecte care colaborează.

Abstractizarea înseamnă să alegem detaliile relevante: pentru rezervări ne interesează capacitatea și locurile ocupate. Nu avem nevoie de culoarea pereților.

Încapsularea înseamnă să păstrăm datele și regulile împreună și să controlăm cum se modifică starea. Vrem ca numărul de locuri ocupate să se schimbe prin rezerva() și elibereaza().

Facem câmpurile interne private, cu prefixul #. Le putem folosi doar în interiorul clasei. Un getter ne permite să citim o valoare folosind sintaxa unei proprietăți.

class SalaCinema {
  #capacitate;
  #ocupate = 0;

  constructor(nume, capacitate) {
    if (!Number.isInteger(capacitate) || capacitate <= 0) {
      throw new Error("Capacitatea trebuie să fie un număr întreg pozitiv.");
    }
    this.nume = nume;
    this.#capacitate = capacitate;
  }

  get capacitate() {
    return this.#capacitate;
  }

  get ocupate() {
    return this.#ocupate;
  }

  get libere() {
    return this.#capacitate - this.#ocupate;
  }

  rezerva() {
    if (this.libere === 0) return false;
    this.#ocupate++;
    return true;
  }

  elibereaza() {
    if (this.#ocupate === 0) return false;
    this.#ocupate--;
    return true;
  }
}

sala.libere apelează getterul, fără paranteze. Numărul este calculat din starea curentă. Din afara clasei nu putem accesa sala.#ocupate. Un nume ca _ocupate ar fi doar o convenție, nu un câmp privat.

// Rulează după definiția clasei SalaCinema de mai sus.
const sala = new SalaCinema("Orion", 2);
console.log(sala.rezerva()); // true
console.log(sala.rezerva()); // true
console.log(sala.rezerva()); // false: sala este plină.
console.log(sala.libere);    // 0
sala.elibereaza();
console.log(sala.libere);    // 1

Două săli, două stări

Rezervă toate locurile din Orion. Observă că Luna rămâne liberă, apoi eliberează un loc și rezervă-l din nou.

Orion

Ocupate: 0 · Libere: 4 din 4

Luna

Ocupate: 0 · Libere: 6 din 6

Loc alb = liber · loc mov = ocupat. Numerele de deasupra arată aceeași stare.

Cum conectăm clasa la buton? 
// Presupunem că HTML-ul are #rezerva și #rezultat.
// Refolosim SalaCinema de mai sus.
const sala = new SalaCinema("Orion", 4);
const buton = document.querySelector("#rezerva");

7. Moștenire: un bilet de student este un bilet

Cu extends, o clasă moștenește comportamentul alteia. Poate adăuga metode sau poate suprascrie o metodă pentru a schimba rezultatul.

class Bilet {
  constructor(film, pret) {
    this.film = film;
    this.pret = pret;
  }

  calculeazaPret() {
    return this.pret;
  }
}

class BiletStudent extends Bilet {
  calculeazaPret() {
    return super.calculeazaPret() / 2;
  }
}

const standard = new Bilet("Aventura pe Lună", 20);
const student = new BiletStudent("Aventura pe Lună", 20);
console.log(standard.calculeazaPret()); // 20
console.log(student.calculeazaPret());  // 10

super.calculeazaPret() apelează metoda din clasa părinte. Reducerea de 50% este regula aleasă pentru exemplul nostru. Fără constructor propriu în clasa copil, argumentele sunt transmise constructorului părinte.

Polimorfism: același apel, comportamente diferite

// Continuă exemplul de mai sus.
const bilete = [standard, student];

for (const bilet of bilete) {
  console.log(bilet.calculeazaPret());
}
// 20, apoi 10

Bucla cere fiecărui obiect să își calculeze prețul. Nu verifică dacă biletul este standard sau de student. Acesta este un exemplu de polimorfism.

În JavaScript, obiectele pot oferi aceeași metodă și fără un părinte comun. Pentru codul de mai sus contează să poată răspunde la apelul calculeazaPret().

8. Compoziție: o comandă are bilete

O comandă nu este un bilet. Ea conține bilete și le folosește. Această relație se numește compoziție.

class Comanda {
  constructor() {
    this.bilete = [];
  }

  adauga(bilet) {
    this.bilete.push(bilet);
  }

  stergeUltimul() {
    this.bilete.pop();
  }

  goleste() {
    this.bilete = [];
  }

  calculeazaTotal() {
    let total = 0;
    for (const bilet of this.bilete) {
      total += bilet.calculeazaPret();
    }
    return total;
  }
}
// Refolosim Bilet și BiletStudent din secțiunea 7 și Comanda de mai sus.
const comanda = new Comanda();
comanda.adauga(new Bilet("Aventura pe Lună", 20));
comanda.adauga(new BiletStudent("Aventura pe Lună", 20));
console.log(comanda.calculeazaTotal()); // 30
comanda.stergeUltimul();
console.log(comanda.calculeazaTotal()); // 20
comanda.goleste();
console.log(comanda.calculeazaTotal()); // 0

Array-ul bilete este creat în constructor: fiecare comandă are propria listă. Calculul totalului folosește metoda fiecărui bilet.

Casa de bilete

Adaugă un bilet standard și unul de student. Încearcă apoi încă un bilet standard: totalul ar trebui să fie 50 lei.

Aventura pe Lună

    Bilete: 0 · Total: 0 lei

    Este un → BiletStudent este un Bilet, folosim moștenire.
    Are → Comanda are bilete, folosim compoziție.

    9. static: apelăm pe clasă

    O metodă obișnuită lucrează cu o instanță. O metodă statică se apelează pe clasă. De exemplu, putem transforma un obiect simplu primit ca date într-un bilet.

    // Variantă completă a clasei Bilet; rulează separat.
class Bilet {
  static moneda = "lei";

  constructor(film, pret) {
    this.film = film;
    this.pret = pret;
  }

  calculeazaPret() {
    return this.pret;
  }

  static dinDate(date) {
    return new Bilet(date.film, date.pret);
  }
}

const date = { film: "Aventura pe Lună", pret: 20 };
const bilet = Bilet.dinDate(date);
console.log(bilet.calculeazaPret()); // 20
console.log(Bilet.moneda);          // "lei"
console.log(bilet.moneda);          // undefined

    dinDate și moneda aparțin clasei. calculeazaPret se apelează pe un bilet. Un obiect simplu obținut prin JSON.parse() nu primește automat metodele clasei.

    Temă simplă: gustări la cinema

    Creează clasa Gustare cu proprietățile nume, pret și stoc. Folosește un stoc inițial întreg, mai mare sau egal cu zero.

    1. Constructorul primește cele trei valori.
    2. Metoda vinde() scade stocul cu 1 și întoarce true. Dacă stocul este 0, întoarce false și nu îl modifică.
    3. Creează popcorn cu prețul de 12 lei și stoc 2, apoi limonadă cu prețul de 10 lei și stoc 3.
    4. Încearcă să vinzi popcorn de trei ori. Afișează rezultatele și stocul ambelor produse.

    Verificare: rezultatele sunt true, true, false. Stocul de popcorn ajunge la 0, iar cel de limonadă rămâne 3.

    Arată rezolvarea 
    class Gustare {
  constructor(nume, pret, stoc) {
    this.nume = nume;
    this.pret = pret;
    this.stoc = stoc;
  }

  vinde() {
    if (this.stoc === 0) return false;
    this.stoc--;
    return true;
  }
}

const popcorn = new Gustare("Popcorn", 12, 2);
const limonada = new Gustare("Limonadă", 10, 3);
console.log(popcorn.vinde()); // true
console.log(popcorn.vinde()); // true
console.log(popcorn.vinde()); // false
console.log(popcorn.stoc);    // 0
console.log(limonada.stoc);   // 3

    Metoda modifică doar stocul obiectului pe care este apelată. Verificarea de la început oprește vânzarea când produsul s-a epuizat.

    Temă puțin mai complexă: bilet cu meniu

    Refolosește clasele Bilet din secțiunea 7 și Comanda din secțiunea 8.

    1. Creează BiletCuMeniu extends Bilet.
    2. Constructorul primește filmul, prețul biletului și prețul meniului. Apelează super(film, pret) înainte să folosești this, apoi salvează prețul meniului.
    3. Suprascrie calculeazaPret() pentru a aduna prețul biletului cu cel al meniului.
    4. Adaugă într-o comandă un bilet standard de 20 lei și un bilet de 20 lei cu meniu de 8 lei.
    5. Afișează totalul, apoi șterge ultimul bilet și afișează din nou totalul.

    Verificare: totalul este 48 lei, apoi 20 lei. Clasa Comanda trebuie să funcționeze fără modificări.

    Arată rezolvarea 
    // Refolosim Bilet și Comanda din lecție.
class BiletCuMeniu extends Bilet {
  constructor(film, pret, pretMeniu) {
    super(film, pret);
    this.pretMeniu = pretMeniu;
  }

  calculeazaPret() {
    return super.calculeazaPret() + this.pretMeniu;
  }
}

const comanda = new Comanda();
comanda.adauga(new Bilet("Aventura pe Lună", 20));
comanda.adauga(new BiletCuMeniu("Aventura pe Lună", 20, 8));
console.log(comanda.calculeazaTotal()); // 48
comanda.stergeUltimul();
console.log(comanda.calculeazaTotal()); // 20

    super(...) inițializează partea moștenită a instanței. Comanda continuă să apeleze aceeași metodă pe fiecare bilet; noua clasă furnizează propriul calcul.
