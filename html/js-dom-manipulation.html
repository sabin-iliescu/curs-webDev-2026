1. DOM-ul: pagina văzută ca un arbore

DOM înseamnă Document Object Model. Browserul citește HTML-ul și construiește obiecte legate între ele. JavaScript poate găsi aceste obiecte și le poate modifica.

<body>
  <main id="cinema">
    <h1>Seară de film</h1>
    <button id="rezerva" type="button">Alege un loc</button>
  </main>
</body>
document
└── html
    ├── head
    └── body
        └── main#cinema
            ├── h1
            └── button#rezerva
  • main este părintele lui h1 și al butonului.
  • h1 și button sunt copii ai lui main și frați între ei.
  • Și textul din elemente este reprezentat prin noduri. Nu toate nodurile sunt elemente HTML.

document reprezintă pagina curentă; window reprezintă fereastra browserului și oferă, de exemplu, alert(). Putem începe căutarea din document, apoi căuta doar în interiorul unui element găsit.

Modificarea DOM-ului schimbă pagina deschisă în browser, nu fișierul HTML de pe disc. Fără salvare separată, schimbările nu devin permanente.

2. Mai întâi HTML-ul, apoi codul care îl caută

Într-un folder de exercițiu creează index.html și script.js. În <head> leagă scriptul astfel:

<script src="script.js" defer></script>

defer permite descărcarea fișierului în timp ce se citește HTML-ul și amână execuția până după parcurgerea HTML-ului. Butonul există deja când îl căutăm.

// În script.js, fără etichete <script>:
const buton = document.getElementById("rezerva");
console.log(buton); // Elementul găsit, dacă HTML-ul de mai sus există.

DOMContentLoaded și load

DOMContentLoaded anunță că HTML-ul a fost parcurs și scripturile amânate au rulat. Nu așteaptă încărcarea tuturor imaginilor; unele pot fi deja încărcate. Evenimentul load al ferestrei așteaptă și resursele dependente obișnuite, precum imaginile care nu sunt încărcate leneș.

document.addEventListener("DOMContentLoaded", function () {
  console.log("Structura paginii este pregătită.");
});

window.addEventListener("load", function () {
  console.log("Pagina și resursele așteptate sunt încărcate.");
});

Pentru exercițiile noastre folosim script extern cu defer. Nu mai avem nevoie să învelim tot codul și într-un listener DOMContentLoaded.

3. Selectori: pe cine vrem să schimbăm?

Un selector este o adresă către un element sau un grup de elemente. querySelector și querySelectorAll folosesc selectorii cunoscuți din CSS.

Cinci metode de recunoscut
MetodăExempluRezultat
getElementByIddocument.getElementById("rezerva")Un element sau null. ID fără #.
querySelectordocument.querySelector(".film")Primul element potrivit sau null.
querySelectorAlldocument.querySelectorAll(".film")Un NodeList cu toate potrivirile, posibil gol.
getElementsByClassNamedocument.getElementsByClassName("film")O colecție de elemente. Clasă fără punct.
getElementsByTagNamedocument.getElementsByTagName("button")O colecție de elemente cu acel nume de etichetă.

Lanterna de selectori

Alege selectorul. Cardurile potrivite primesc un contur mov.

  • 🍿 Pauză de râs
  • 🚀 Drum spre Marte
  • 🐈 Pisica regizor

#filme-demo .film → 3 elemente

const primulFilm = document.querySelector("#filme-demo .film");
const toateFilmele = document.querySelectorAll("#filme-demo .film");
console.log(primulFilm.textContent); // 🍿 Pauză de râs
console.log(toateFilmele.length);    // 3

for (const film of toateFilmele) {
  film.classList.add("reperat");
}

#filme-demo .film înseamnă „elemente cu clasa film din interiorul lui filme-demo”. Un NodeList este o colecție, nu un singur element: îl parcurgem înainte de a modifica elementele.

querySelectorAll() oferă o listă statică a potrivirilor de la acel moment. Dacă adaugi ulterior un film, cauți din nou ca să-l incluzi. Colecțiile întoarse de getElementsByClassName și getElementsByTagName se actualizează automat.

Codul complet al lanternei
const selector = document.getElementById("selector-demo");
const filme = document.querySelectorAll("#filme-demo .film");
const selectorRezultat = document.getElementById("selector-rezultat");

function evidentiazaFilmele() {
  for (const film of filme) {
    film.classList.remove("reperat");
  }
  const gasite = document.querySelectorAll(selector.value);
  for (const film of gasite) {
    film.classList.add("reperat");
  }
  selectorRezultat.textContent = `${selector.value} → ${gasite.length} elemente`;
}
selector.addEventListener("change", evidentiazaFilmele);
evidentiazaFilmele();

4. textContent și value: mesajul tău pe ecran

textContent citește sau schimbă textul unui element. value citește sau schimbă valoarea unui câmp de formular.

<label for="nume-demo">Cum te cheamă?</label>
<input id="nume-demo" type="text" maxlength="40" />
<p id="salut-demo" aria-live="polite">Salut, cinefilule!</p>

Afișul te salută pe nume

Salut, cinefilule! Ce film alegem?

Încearcă și <b>Mara</b>. Îl afișăm ca text, fără să-l transformăm în HTML.

const numeInput = document.getElementById("nume-demo");
const salut = document.getElementById("salut-demo");

function actualizeazaSalutul() {
  const nume = numeInput.value.trim();
  if (nume === "") {
    salut.textContent = "Salut, cinefilule! Ce film alegem?";
  } else {
    salut.textContent = `Salut, ${nume}! Ce film alegem?`;
  }
}
numeInput.addEventListener("input", actualizeazaSalutul);
actualizeazaSalutul();

input se declanșează pe măsură ce scrii, ștergi sau lipești text. trim() elimină spațiile de la capete. Funcția este apelată o dată și la pornire, ca mesajul să corespundă câmpului.

Când folosim innerHTML?

const mesaj = document.getElementById("salut-demo");
mesaj.textContent = "Bilet <strong>VIP</strong>"; // Afișează și etichetele.
mesaj.innerHTML = "Bilet <strong>VIP</strong>";   // Creează un element <strong>.

innerHTML interpretează un șir ca HTML și înlocuiește conținutul interior. Pentru text introdus de utilizator folosim textContent. Pentru elemente noi folosim createElement, explicat mai jos.

Dacă înlocuiești tot conținutul unui container prin innerHTML sau textContent, dispar și vechile elemente copil. Listenerii atașați acelor copii nu se transferă pe elementele noi.

5. Atribute și proprietăți: aceeași etichetă, alt comportament

Atributele sunt scrise în HTML: id, href, title. Proprietățile sunt valorile obiectului DOM, precum value, checked și disabled.

const link = document.querySelector("a");
console.log(link.getAttribute("href")); // Citim un atribut.
link.setAttribute("title", "Deschide lecția precedentă");
link.removeAttribute("title");         // Eliminăm atributul.

const camp = document.getElementById("nume-demo");
console.log(camp.value); // Textul curent, inclusiv modificările utilizatorului.

Butonul așteaptă un „da”

Bifează că ai verificat ora filmului.

const acord = document.getElementById("acord-demo");
const continua = document.getElementById("continua-demo");
const acordMesaj = document.getElementById("acord-mesaj");

acord.addEventListener("change", function () {
  continua.disabled = !acord.checked;
  acordMesaj.textContent = acord.checked
    ? "Butonul este activ. Poți continua."
    : "Bifează că ai verificat ora filmului.";
});
continua.addEventListener("click", function () {
  acordMesaj.textContent = "Gata, ne vedem la film!";
});

checked este true sau false. Cu ! inversăm valoarea: butonul este dezactivat când căsuța nu este bifată.

Pentru activare scriem buton.disabled = false sau eliminăm atributul. setAttribute("disabled", "false") tot dezactivează butonul: la atributele HTML booleene contează prezența, nu textul „false”. În schimb, aria-pressed="false" are un sens explicit.

6. classList: schimbăm starea, CSS schimbă aspectul

Păstrăm culorile în CSS și folosim JavaScript pentru a adăuga sau scoate clase.

.mod-seara {
  background: #20162c;
  color: #f8fafc;
}

Începe filmul

Luminile aprinse pentru discuții. Modul seară pentru proiecție.

const scena = document.getElementById("scena-demo");
const lumina = document.getElementById("lumina-demo");

lumina.addEventListener("click", function () {
  const esteSeara = scena.classList.toggle("mod-seara");
  lumina.setAttribute("aria-pressed", String(esteSeara));
  lumina.textContent = esteSeara ? "Aprinde luminile" : "Activează modul seară";
});
  • classList.add("mod-seara") adaugă clasa.
  • classList.remove("mod-seara") o elimină.
  • classList.toggle("mod-seara") alternează starea și returnează dacă acum clasa există.
  • classList.contains("mod-seara") verifică dacă există.

aria-pressed comunică și cititoarelor de ecran dacă butonul de tip comutator este activ. Schimbăm și eticheta butonului, pentru ca acțiunea următoare să fie clară.

Putem schimba și un stil punctual: scena.style.fontSize = "20px". Proprietatea CSS font-size se scrie fontSize în JavaScript. Pentru un set de reguli, o clasă rămâne mai ușor de întreținut.

    8. Navigăm prin DOM: părinți, copii și frați

    După ce găsim un element, putem afla cine este lângă el fără să reluăm căutarea în toată pagina.

    const film = document.getElementById("film-spatiu");
console.log(film.parentElement.id);                   // "filme-demo"
console.log(film.previousElementSibling.textContent); // 🍿 Pauză de râs
console.log(film.nextElementSibling.textContent);     // 🐈 Pisica regizor
console.log(film.parentElement.children.length);      // 3
console.log(film.closest(".demo").id);                // "demo-selectori"
    • parentElement: părintele element.
    • children: doar copiii care sunt elemente.
    • firstElementChild / lastElementChild: primul / ultimul copil element.
    • previousElementSibling / nextElementSibling: fratele element anterior / următor.
    • closest(selector): verifică elementul curent, apoi urcă spre părinți până la prima potrivire.

    Dacă nu există o potrivire, multe dintre aceste căutări întorc null. firstChild și childNodes includ și noduri text, inclusiv spațiile și liniile noi din HTML. Pentru elemente, folosim variantele cu „Element” sau children.

    9. Evenimente: pagina ascultă acțiunile utilizatorului

    Un eveniment anunță că s-a întâmplat ceva. Un listener este funcția pe care o conectăm ca să reacționeze.

    const buton = document.getElementById("continua-demo");
function anuntaClickul(event) {
  console.log("Am primit evenimentul:", event.type);
}
buton.addEventListener("click", anuntaClickul);

    Trimitem funcția fără (), ca să fie apelată la eveniment. Browserul îi oferă obiectul event, cu informații despre ce s-a întâmplat.

    • click: activarea unui buton cu mouse-ul, atingerea sau tastatura.
    • input: editarea valorii unui câmp, pe măsură ce se schimbă.
    • change: alegerea unei opțiuni din select sau schimbarea unei bife; la un câmp text apare de obicei la confirmarea modificării prin ieșirea din câmp.
    • submit: trimiterea formularului, inclusiv prin Enter.
    • keydown: apăsarea unei taste; event.key spune care.

    addEventListener permite mai multe funcții pentru același tip de eveniment. Atribuirea la onclick înlocuiește funcția din acea proprietate. În lecție folosim addEventListener.

    Cum oprim un listener?

    Cu removeEventListener, folosind aceeași funcție și același tip de eveniment. O funcție nouă, chiar cu același cod, nu o elimină pe cea veche. Dacă ai setat opțiunea capture, și aceasta trebuie să coincidă.

    Aplauze cu pauză

    Aplauze: 0

    const aplauze = document.getElementById("aplauze-demo");
const pauza = document.getElementById("pauza-demo");
const reia = document.getElementById("reia-demo");
const aplauzeMesaj = document.getElementById("aplauze-mesaj");

function numaraAplauze() {

    10. Un singur listener pentru mai multe butoane

    Un click poate urca de la elementul apăsat spre părinții lui. Acest comportament se numește bubbling. Îl folosim pentru delegare: ascultăm pe container și aflăm ce copil a fost apăsat.

    <div id="zona-click">
  <button class="gustare" data-produs="Popcorn" type="button">
    <span>🍿 Popcorn</span>
  </button>
</div>

    Pe buton sau pe textul din el?

    Apasă direct pe text, apoi pe marginea unui buton și observă rezultatul.

    Aștept un click.

    const zona = document.getElementById("zona-click");
const urma = document.getElementById("urma-click");

zona.addEventListener("click", function (event) {
  const buton = event.target.closest(".gustare");
  if (buton === null) {
    urma.textContent = "Ai apăsat spațiul dintre butoane. Nu alegem nimic.";
    return;
  }
  urma.textContent = `target: ${event.target.tagName}; currentTarget: ${event.currentTarget.tagName}; alegere: ${buton.dataset.produs}`;
});
    • event.target este elementul de la care a pornit clickul. Poate fi span-ul din buton.
    • event.currentTarget este elementul pe care am conectat listenerul: containerul div.
    • closest(".gustare") găsește butonul, chiar dacă am apăsat pe copilul său.
    • data-produs păstrează o informație simplă în HTML; o citim prin dataset.produs.

    Un click pe spațiul gol nu găsește un buton, deci ieșim prin return. preventDefault() oprește acțiunea implicită, precum trimiterea unui formular; nu oprește propagarea evenimentului.

    Delegarea funcționează și pentru butoane adăugate ulterior în container. Nu trebuie să conectăm un listener separat fiecărui buton nou. Vom folosi același principiu pentru cele 48 de locuri din sală.

    11. Trei întrebări înainte de workshop

    De ce primesc „Cannot read properties of null”?

    Selectorul nu a găsit un element. Verifică ID-ul, diferența dintre getElementById("nume") și querySelector("#nume"), apoi prezența lui defer. Verifică și dacă acel element chiar există pe pagina curentă.

    De ce nu se actualizează lungimea unui querySelectorAll mai vechi?

    Lista este statică. Apelează din nou querySelectorAll() când vrei potrivirile actuale. În workshop vom căuta locurile selectate în interiorul funcției de actualizare.

    Cum evit să selectez și scaunul verde din legendă?

    Caut doar în sala cu locuri: container.querySelectorAll(".seat.selected"). Un selector limitat la container nu include elemente decorative din afara lui.

    Pasul 4: găsim piesele în JavaScript

    Începem fișierul movie-tickets.js cu referințe către elementele de care avem nevoie:

    // Pasul 4: găsim elementele și citim prețul inițial.
const container = document.getElementById("seats");

    Elementele sunt păstrate în const: vom modifica proprietățile lor, nu vom reatribui variabilele. ticketPrice folosește let, pentru că se schimbă atunci când alegem alt film.

    movieSelect.value este text, de exemplu "10". Number() îl transformă în numărul 10, pe care îl folosim la calcule.

    Pasul 5: o singură funcție actualizează rezumatul

    În loc să repetăm calculul în fiecare listener, scriem o funcție și o apelăm după orice schimbare relevantă.

    // Pasul 5: aceeași funcție actualizează toate valorile afișate.
function updateSelectedCount() {
  const selectedSeats = container.querySelectorAll(".seat.selected");
  const selectedSeatsCount = selectedSeats.length;
  count.textContent = selectedSeatsCount;
  price.textContent = ticketPrice;
  total.textContent = selectedSeatsCount * ticketPrice;
}
    1. Căutăm .seat.selected numai în sala container.
    2. length spune câte locuri sunt alese.
    3. Scriem numărul și prețul în elementele pregătite în HTML.
    4. Înmulțim cantitatea cu prețul și afișăm totalul.

    Căutarea este în interiorul funcției, deci se repetă la fiecare actualizare. Dacă am păstra o listă statică a locurilor selectate doar la pornire, ar rămâne goală chiar după clickuri.

    Verifică: apelează temporar updateSelectedCount(). Cu zero locuri selectate, numărul și totalul sunt 0. Definirea funcției, singură, nu o execută.

    Pasul 6: click pe loc → schimbare de clasă → recalculare

    Conectăm listenerul la containerul sălii. El primește și clickurile care pornesc din butoanele din interior.

    // Pasul 6: un singur listener pentru toate locurile.
container.addEventListener("click", function (event) {
  const seat = event.target.closest(".seat");
  if (seat === null || seat.classList.contains("occupied") || seat.disabled) {
    return;
  }
  const isSelected = seat.classList.toggle("selected");
  seat.setAttribute("aria-pressed", String(isSelected));
  updateSelectedCount();
});
    1. closest(".seat") găsește butonul, chiar dacă target este textul din span.
    2. Dacă nu am apăsat un loc sau locul este ocupat/dezactivat, ieșim imediat.
    3. toggle("selected") selectează sau deselectează locul.
    4. Actualizăm aria-pressed în același timp cu starea vizuală.
    5. Apelăm funcția care recalculează rezumatul.

    Nu creștem manual un contor la fiecare click. Numărăm locurile care au clasa potrivită acum, astfel încât și deselectarea să fie tratată corect.

    Verifică: cu Rocky la 10 lei, alege A1 și A2: 2 bilete, 20 lei. Apasă iar A1: 1 bilet, 10 lei. Un loc ocupat nu schimbă nimic.

    Pasul 7: alt film, alt preț

    // Pasul 7: schimbarea filmului actualizează prețul și totalul.
movieSelect.addEventListener("change", function () {
  ticketPrice = Number(movieSelect.value);
  updateSelectedCount();
});

    change apare când utilizatorul schimbă opțiunea selectată. Citim noul preț, apoi actualizăm totalul pentru locurile care sunt deja alese.

    Ordinea contează: mai întâi schimbăm ticketPrice, apoi calculăm. Dacă am apela funcția înaintea atribuirii, am afișa totalul cu prețul vechi.

    Verifică: păstrează două locuri selectate și schimbă Rocky cu Joker. Numărul rămâne 2, prețul devine 12 lei, iar totalul este 24 lei.

    Pasul 8: golim selecția

    // Pasul 8: golim selecția, păstrând filmul ales.
resetButton.addEventListener("click", function () {
  const selectedSeats = container.querySelectorAll(".seat.selected");
  for (const seat of selectedSeats) {
    seat.classList.remove("selected");
    seat.setAttribute("aria-pressed", "false");
  }
  updateSelectedCount();
});

    Căutăm locurile selectate și le eliminăm clasa, unul câte unul. Actualizăm și starea anunțată de cititoarele de ecran. Recalculăm rezumatul o singură dată, după buclă.

    Butonul „Golește selecția” păstrează filmul ales și locurile ocupate. Dacă selecția era deja goală, bucla nu are elemente de parcurs și rezultatul rămâne 0.

    Verifică: după golire, nu mai ai locuri verzi, numărul și totalul sunt 0, iar cele nouă locuri ocupate rămân blocate.

function updateSelectedCount() {

  const selectedSeatsCount = selectedSeats.length;
  count.textContent = selectedSeatsCount;

// Pasul 6: un singur listener pentru toate locurile.
container.addEventListener("click", function (event) {
  const seat = event.target.closest(".seat");
  if (seat === null || seat.classList.contains("occupied") || seat.disabled) {
    return;
  }
  const isSelected = seat.classList.toggle("selected");
  seat.setAttribute("aria-pressed", String(isSelected));
  updateSelectedCount();
});

// Pasul 7: schimbarea filmului actualizează prețul și totalul.
movieSelect.addEventListener("change", function () {
  ticketPrice = Number(movieSelect.value);
  updateSelectedCount();
});

// Pasul 8: golim selecția, păstrând filmul ales.
resetButton.addEventListener("click", function () {
  const selectedSeats = container.querySelectorAll(".seat.selected");
  for (const seat of selectedSeats) {
    seat.classList.remove("selected");
    seat.setAttribute("aria-pressed", "false");
  }
  updateSelectedCount();
});

    Temă simplă: lista pentru seara de film

    Creează o pagină cu un formular pentru titlul unui film și o listă inițial goală.

    1. La submit, oprește reîncărcarea paginii.
    2. Verifică titlul după trim(). Dacă este gol, afișează un mesaj.
    3. Creează un li și afișează titlul cu textContent.
    4. Adaugă un buton „Văzut”, care alternează clasa vazut pe acel rând. În CSS, clasa taie textul titlului.
    5. Adaugă un buton „Șterge” și actualizează numărul total de filme.

    Verificare: adaugi două filme → contorul este 2. Marchezi unul ca văzut → contorul rămâne 2. Ștergi unul → contorul este 1. Un titlu gol nu creează niciun rând.
