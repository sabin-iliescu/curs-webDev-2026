03 - Formulare HTML

Formularele colectează informații introduse de utilizator.

1. Elementul form

Toate câmpurile unui formular sunt puse în elementul <form>.

<form>... câmpurile formularului ...</form>

Atributul action spune unde sunt trimise datele, iar method stabilește metoda de trimitere, de obicei get sau post.

<form action="/contact" method="post">

2. Părțile principale ale unui formular

  1. Etichete — explică rolul câmpurilor.
  2. Câmpuri — primesc informațiile.
  3. Acțiuni — trimit sau resetează formularul.
  4. Ajutor — explică ce trebuie completat.
  5. Mesaje — oferă feedback utilizatorului.
  6. Validare — verifică datele introduse.

3. Label și input

<label> este legat de câmp prin atributele for și id. Apasă pe etichetă și câmpul va fi selectat.

<label for="prenume">Prenume:</label>
<input id="prenume" name="prenume" type="text" />

4. Câmpuri pentru text

Un câmp hidden este trimis împreună cu formularul, dar nu este afișat utilizatorului.

<input name="sursa" type="hidden" value="lectia-03" />

5. Checkbox și radio

Checkbox-urile permit selectarea mai multor variante.

Butoanele radio cu același name permit o singură alegere.

6. Select și option

Ține apăsat Ctrl sau Cmd pentru selecție multiplă.

7. Alte tipuri de input

8. Fieldset și legend

<fieldset> grupează câmpuri, iar <legend> denumește grupul.

Date personale

9. Butoanele formularului

  • submit încearcă să trimită formularul;
  • reset readuce câmpurile la valorile inițiale;
  • button nu are o acțiune implicită.

10. Validare simplă

Browserul poate verifica unele date fără JavaScript:

  • required face câmpul obligatoriu;
  • minlength și maxlength controlează lungimea;
  • min și max limitează numerele;
  • type="email" verifică forma adresei de e-mail.

<input type="email" required />

11. Formular complet de test

Completează formularul și testează butoanele. Datele nu sunt trimise unui server.

12. Reguli simple

  • Folosește un <label> pentru fiecare câmp.
  • Folosește un id unic pentru fiecare control.
  • Folosește atributul name pentru datele care trebuie trimise.
  • Grupează opțiunile asociate cu <fieldset>.
  • Marchează clar câmpurile obligatorii.
  • Oferă mesaje de ajutor scurte și ușor de înțeles.
