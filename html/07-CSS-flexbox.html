07 - CSS Flexbox

Așezarea elementelor în rânduri și coloane, pas cu pas.

1. Ce este Flexbox?

Flexbox este un sistem CSS pentru așezarea și alinierea elementelor. Este foarte util pentru meniuri, carduri și centrare.

Flexbox controlează elementele pe o singură direcție principală: rând sau coloană.

2. Container și items

Elementul părinte devine flex container, iar copiii direcți devin flex items.

<div class="container">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>
.container {
  display: flex;
}

3. Primul pas: display flex

O singură proprietate activează Flexbox pentru copiii direcți:

.container {
  display: flex;
}

Elementele sunt așezate implicit într-un rând, de la stânga la dreapta.

4. Axa principală și axa secundară

  • Main axis este direcția în care sunt așezate elementele.
  • Cross axis este direcția perpendiculară.

Dacă direcția este row, axa principală este orizontală. Dacă direcția este column, axa principală este verticală.

6. Gap

gap creează spațiu egal între flex items.

.container {
  display: flex;
  gap: 16px;
}

Pentru spațiul dintre elemente, gap este adesea mai simplu decât marginile individuale.

10. Flex wrap

Implicit, elementele încearcă să rămână pe un singur rând. flex-wrap: wrap le permite să treacă pe rândul următor.

11. Flex grow

flex-grow spune cât din spațiul liber poate primi un element.

grow: 1
grow: 2
grow: 1

Elementul cu valoarea 2 încearcă să primească mai mult din spațiul disponibil.

12. Flex basis și flex shrink

  • flex-basis propune dimensiunea inițială a elementului;
  • flex-shrink spune dacă elementul se poate micșora.
.item {
  flex-basis: 200px;
  flex-shrink: 1;
}

13. Proprietatea flex

flex este prescurtarea pentru grow, shrink și basis.

.item {
  flex: 1 1 180px;

Această variantă spune: poate crește, se poate micșora și pornește de la aproximativ 180px.

14. Align self

align-self schimbă alinierea unui singur flex item.

15. Order

order poate schimba ordinea vizuală a unui element.

.item-special {
  order: -1;
}

Folosește order cu grijă. Ordinea din HTML rămâne importantă pentru tastatură și cititoarele de ecran.

18. Greșeli frecvente

  • Aplicarea proprietăților Flexbox pe elementul greșit.
  • Uitarea proprietății display: flex.
  • Confundarea axei principale cu axa secundară.
  • Uitarea proprietății flex-wrap când nu există spațiu.
  • Folosirea Flexbox când normal flow este deja suficient.

19. Mini-exercițiu

Creează un meniu cu un logo și trei linkuri.

  1. Folosește display: flex.
  2. Pune logo-ul și linkurile la capete cu space-between.
  3. Centrează elementele vertical.
  4. Adaugă spațiu între linkuri cu gap.

20. Exercițiu puțin mai complex

Creează o secțiune cu patru carduri de curs.

  1. Fiecare card conține titlu, descriere și buton.
  2. Așază cardurile pe un rând cu Flexbox.
  3. Permite trecerea lor pe rând nou.
  4. Folosește flex: 1 1 220px pentru carduri.
  5. Folosește gap pentru spațiere.
  6. Aliniază butonul la finalul fiecărui card.
  7. Testează pagina la o lățime mică.

21. Recapitulare

  • Părintele primește display: flex.
  • Copiii direcți devin flex items.
  • justify-content lucrează pe axa principală.
  • align-items lucrează pe axa secundară.
  • flex-wrap permite trecerea pe rând nou.
  • flex controlează flexibilitatea elementelor.
