06 - CSS Advanced

Tranziții, transformări și animații explicate foarte simplu.

1. Ce înseamnă CSS Advanced aici?

În această lecție adăugăm mișcare și efecte vizuale. Nu avem nevoie de JavaScript pentru exemplele de bază.

  • transition - face o schimbare mai lină;
  • transform - mută, rotește sau redimensionează;
  • animation - rulează mai multe etape definite de noi.

2. Normal flow - recapitulare

În mod normal, browserul afișează elementele în ordinea în care apar în HTML. Elementele block sunt așezate unul sub altul.

3. Position - recapitulare

  • static - poziția normală;
  • relative - elementul devine reper;
  • absolute - elementul este poziționat față de reper;
  • fixed - elementul rămâne fix în fereastră;
  • sticky - elementul se fixează în timpul derulării.
Părinte cu position: relative Copil absolute

4. Ce este o tranziție?

Fără tranziție, o proprietate se schimbă imediat. Cu transition, schimbarea are loc treptat. 

.buton {
  background-color: purple;
  transition: background-color 0.3s ease;
}

.buton:hover {
  background-color: green;
}

5. Părțile unei tranziții

ProprietateRol
transition-propertyCe proprietate se animă
transition-durationCât durează
transition-timing-functionCum se schimbă viteza
transition-delayCât așteaptă înainte să înceapă
 
transition: transform 0.3s ease;

6. Ce face transform?

transform schimbă vizual un element fără să mute celelalte elemente din jur.

translate
scale
rotate
skew

7. Transformări de bază

transform: translateX(20px); /* mută */
transform: scale(1.2);       /* mărește */
transform: rotate(10deg);    /* rotește */
transform: skewX(10deg);     /* înclină */

Putem combina mai multe transformări pe aceeași linie:

transform: translateY(-4px) scale(1.05);

8. Transition și transform împreună

Card demonstrativ

Treci cu mouse-ul peste card.

.card {
  transition: transform 0.25s ease;
}

.card:hover {
  transform: scale(1.04);
}

9. Ce este o animație CSS?

O animație poate avea mai multe etape și poate porni fără ca utilizatorul să treacă mouse-ul peste element.

10. Keyframes

@keyframes definește începutul și sfârșitul animației.

@keyframes plimbare {
  from { transform: translateX(0); }
  to { transform: translateX(220px); }
}

.minge {
  animation: plimbare 2s infinite alternate;
}

11. Proprietățile unei animații

ProprietateRol
animation-nameNumele keyframes
animation-durationDurata unui ciclu
animation-delayÎntârzierea
animation-iteration-countNumărul de repetări
animation-directionDirecția animației
animation-timing-functionModul în care variază viteza

12. Un exemplu de animație subtilă

Mesaj important

Animațiile mici pot atrage atenția. Prea multe animații pot obosi sau distrage utilizatorul.

13. Accesibilitate și mișcare

Unele persoane preferă mai puțină mișcare. Putem respecta setarea lor cu media query-ul prefers-reduced-motion. 

@media (prefers-reduced-motion: reduce) {
  * {
    animation: none;
    transition: none;
  }
}

14. Verificare în DevTools

  1. Inspectează butonul cu tranziție.
  2. Activează manual starea :hover.
  3. Modifică durata din 0.3s în 2s.
  4. Dezactivează temporar proprietatea transform.
  5. Observă diferența.

15. Mini-exercițiu

Creează un buton care reacționează la hover.

  1. Schimbă-i culoarea de fundal.
  2. Ridică-l cu translateY(-3px).
  3. Adaugă o tranziție de 0.3s.
  4. Adaugă o umbră discretă.

16. Exercițiu puțin mai complex

Creează un card de produs animat.

  1. Adaugă titlu, descriere, preț și buton.
  2. La hover, mărește cardul foarte puțin.
  3. Schimbă umbra cardului printr-o tranziție.
  4. Adaugă o etichetă „Nou” cu o animație discretă.
  5. Oprește animația pentru prefers-reduced-motion.

17. Recapitulare

  • transition face schimbările mai line.
  • transform mută, mărește sau rotește.
  • @keyframes definește etapele unei animații.
  • Animațiile trebuie folosite cu măsură.
