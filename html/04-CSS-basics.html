04 - CSS Basics

O introducere simplă în stilizarea paginilor HTML.

1. Ce este CSS?

CSS vine de la Cascading Style Sheets și descrie aspectul unei pagini web.

Cu CSS putem controla culorile, fonturile, spațiile, dimensiunile și poziția elementelor.

2. De ce separăm HTML de CSS?

  • HTML-ul rămâne mai ușor de citit.
  • Același CSS poate fi folosit de mai multe pagini.
  • Putem schimba aspectul site-ului dintr-un singur fișier.
  • Conținutul și prezentarea au responsabilități diferite.

3. Anatomia unei reguli CSS

p {
  color: blue;
  font-size: 18px;
}
  • p este selectorul;
  • color și font-size sunt proprietăți;
  • blue și 18px sunt valori;
  • proprietatea și valoarea formează o declarație.

Declarațiile sunt puse între acolade și sunt separate prin punct și virgulă.

4. Comentarii CSS

Comentariile explică codul și nu sunt afișate în pagină.

/* Acesta este un comentariu CSS. */

5. CSS în trei moduri

CSS inline

Acest paragraf folosește atributul style. 

<p style="color: red;">Text roșu</p>

CSS intern

Acest paragraf este stilizat în elementul <style>.

<style>
  p { color: purple; }
</style>

CSS extern

Acest paragraf este stilizat din fișierul 04-styles.css.

<link rel="stylesheet" href="04-styles.css" />

Pentru proiecte reale, CSS-ul extern este de obicei varianta recomandată.

7. Clasă sau ID?

  • O class poate fi folosită pe mai multe elemente.
  • Un id trebuie să fie unic în pagină.
  • Pentru stilizare reutilizabilă preferăm clasele.
<p class="avertisment">Primul mesaj</p>
<p class="avertisment">Al doilea mesaj</p>

.avertisment {
  color: red;
}

8. Gruparea selectorilor

Separăm selectorii prin virgulă când primesc aceleași reguli.

h1,
h2,
h3 {
  font-family: Arial, sans-serif;
  color: purple;
}

9. Selectori descendenți și copii direcți

article p {
  color: blue;
}

article > p {
  font-weight: bold;
}
  • article p selectează paragrafele aflate oriunde în articol;
  • article > p selectează doar paragrafele copil direct.

10. Selectori după atribut

Putem selecta elementele și după atributele lor.

[required] {
  border-color: red;
}

input[type="email"] {
  background-color: lightyellow;
}

a[href^="https"] {
  color: green;
}

11. Pseudo-clase

Pseudo-clasele stilizează un element într-o anumită stare.

button:hover {
  background-color: purple;
}

input:focus {
  outline: 2px solid orange;
}

input:checked {
  accent-color: green;
}

12. Pseudo-elemente

Pseudo-elementele pot stiliza o parte a elementului sau pot adăuga conținut decorativ.

p::first-letter {
  font-size: 32px;
}

.produs::after {
  content: " NOU";
}

Prima literă a acestui paragraf este diferită.

Curs CSS

13. Culori în CSS

Aceeași culoare poate fi scrisă în mai multe moduri.

color: red;
color: #ff0000;
color: rgb(255, 0, 0);
color: hsl(0, 100%, 50%);

La început poți folosi nume de culori sau valori hexazecimale.

16. Box model

Browserul tratează fiecare element ca pe o cutie formată din:

  1. content - conținutul;
  2. padding - spațiul interior;
  3. border - conturul;
  4. margin - spațiul exterior.
Conținutul cutiei
.cutie {
  margin: 24px;
  padding: 24px;
  border: 8px solid blue;
}

17. Moștenirea

Unele proprietăți trec de la părinte la copii.

body {
  color: #222;
  font-family: Arial, sans-serif;
}

Textul din interiorul paginii va moșteni de obicei culoarea și fontul.

Proprietăți precum margin, padding și border nu se moștenesc în mod normal.

18. Ce înseamnă „cascading”?

Dacă mai multe reguli stilizează același element, browserul trebuie să aleagă regula câștigătoare.

  1. importanța regulii;
  2. specificitatea selectorului;
  3. ordinea regulilor în fișier.

Evită !important la început. De obicei putem rezolva problema cu un selector mai clar.

19. Specificitatea, explicată simplu

Un selector mai precis are prioritate față de unul mai general.

p { color: blue; }          /* general */
.mesaj { color: green; }    /* mai specific */
#mesaj-unic { color: red; } /* foarte specific */

Ca regulă simplă: ID-ul cântărește mai mult decât clasa, iar clasa mai mult decât elementul.

20. Ordinea regulilor

Dacă doi selectori au aceeași specificitate, ultima regulă câștigă.

p { color: blue; }
p { color: green; } /* textul va fi verde */

21. Stilurile implicite ale browserului

Browserul aplică propriile stiluri când noi nu scriem CSS.

De aceea titlurile sunt mari, linkurile sunt albastre și listele au marcatori chiar înainte să adăugăm CSS.

* {
  box-sizing: border-box;
}

body {
  margin: 0;
}

22. Verificarea CSS în DevTools

  1. Deschide pagina în Chrome.
  2. Dă click dreapta pe un element și alege Inspect.
  3. În panoul Styles, vezi regulile aplicate.
  4. Debifează o proprietate și observă schimbarea.
  5. Modifică o culoare direct în DevTools.

Schimbările din DevTools sunt temporare. Pentru a le păstra, modifică fișierul CSS.

23. Exemplu HTML + CSS

HTML

<article class="produs">
  <h2>Caiet</h2>
  <p>Un caiet simplu pentru notițe.</p>
  <a href="#">Vezi produsul</a>
</article>

CSS

.produs {
  max-width: 300px;
  padding: 20px;
  background-color: white;
  border: 1px solid #ddd;
  border-radius: 8px;
}

.produs a {
  color: purple;
}

24. Mini-exercițiu

Pornește de la o pagină HTML care conține un titlu, două paragrafe și un link.

  1. Creează un fișier numit exercitiu.css.
  2. Leagă fișierul CSS în elementul <head>.
  3. Schimbă fontul și culoarea de fundal a paginii.
  4. Stilizează titlul folosind selectorul de element.
  5. Adaugă aceeași clasă celor două paragrafe.
  6. Stilizează linkul și schimbă-i culoarea la :hover.

25. Exercițiu puțin mai complex

Creează un card pentru prezentarea unui eveniment.

  1. Adaugă un titlu, o dată, o descriere și un link.
  2. Folosește o clasă .eveniment pentru card.
  3. Adaugă padding, border și border-radius.
  4. Limitează lățimea cardului la 400px.
  5. Stilizează separat data folosind o clasă.
  6. Transformă linkul într-un buton simplu.
  7. Adaugă o stare :hover pentru buton.
  8. Verifică rezultatul în Chrome DevTools.

26. Recapitulare

  • CSS controlează aspectul paginii.
  • O regulă conține selector, proprietăți și valori.
  • CSS poate fi inline, intern sau extern.
  • Clasele sunt potrivite pentru stiluri reutilizabile.
  • Box model explică spațiul ocupat de un element.
  • Cascada decide ce regulă CSS câștigă.
