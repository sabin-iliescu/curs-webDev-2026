10 - JavaScript Basics

HTML pune butonul în pagină. CSS îl face frumos. JavaScript face ceva când îl apeși.

Deschidem o cafenea imaginară și învățăm să ținem minte valori, să calculăm un bon și să luăm decizii. Pas cu pas, fără biblioteci.

  1. Primul script și consola
  2. Variabile, tipuri de date și calcule
  3. Liste și obiecte
  4. Comparații, condiții și bucle
  5. Funcții și primul buton conectat
  6. Recapitulare și teme

Încearcă exemplele pe rând. Schimbă o valoare, ghicește rezultatul, apoi rulează codul.

1. Ce face JavaScript?

JavaScript este un limbaj de programare. În browser îl folosim pentru reacții la click, calcule, validarea formularelor sau actualizarea conținutului unei pagini.

  • HTML: avem un meniu și un buton „Comandă”.
  • CSS: meniul are culori, spațiere și se adaptează la telefon.
  • JavaScript: apăsăm butonul și apare un mesaj.

A apărut în 1995, creat de Brendan Eich. Java și JavaScript sunt limbaje diferite. ECMAScript este standardul care descrie limbajul. JavaScript poate rula și în afara browserului, de exemplu cu Node.js; aici lucrăm în browser.

Un click, o schimbare

Cafeneaua așteaptă primul click.

La finalul lecției vei vedea codul care conectează un buton la un mesaj.

2. Unde scriem codul?

Creează un folder cu două fișiere: index.html și script.js. Deschide HTML-ul în browser. Nu avem nevoie de CDN sau de instalări pentru JavaScript simplu.

Fișierul index.html

<!doctype html>
<html lang="ro">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Prima mea cafenea</title>
    <script src="script.js" defer></script>
  </head>
  <body>
    <h1>Cafea și cod</h1>
  </body>
</html>

Fișierul script.js

console.log("Cafeneaua este deschisă!");

src indică fișierul. defer permite descărcarea scriptului în timp ce browserul citește HTML-ul și amână rularea până când acesta a fost parcurs. Astfel, elementele HTML sunt disponibile când le căutăm în script.

În fișierul .js scriem direct JavaScript, fără etichete <script>. Salvăm fișierul și reîncărcăm pagina pentru a vedea schimbările.

Alternativă: JavaScript direct în HTML

Pentru un test scurt, poți pune acest cod înainte de </body>. Alege o singură variantă pentru același exemplu, ca să nu îl rulezi de două ori.

<script>
  console.log("Salut din HTML!");
</script>

defer se folosește pe scripturi externe clasice; nu are efect pe acest script scris direct în HTML. Un src poate indica și un URL extern, ca la bibliotecile din lecția precedentă.

3. Consola: locul în care vedem ce se întâmplă

  1. În Chrome sau Edge, click dreapta pe pagină → Inspect / Inspectează.
  2. Deschide fila Console.
  3. Scrie 2 + 3 și apasă Enter. Rezultatul este 5.
  4. Reîncarcă pagina creată mai sus. Apare mesajul din script.js.
// Comentariu pe o linie: explică, dar nu se execută.
console.log("Salut!"); // Afișează textul în consolă.
console.log(2 + 3);    // Afișează 5.

/* Un comentariu poate ocupa
   mai multe linii. */

console.log() afișează valori în consolă, nu în pagină. Ghilimelele delimitează textul; parantezele conțin ce vrem să afișăm. În exemple încheiem instrucțiunile cu ;.

După un console.log() rulat direct în consolă poți vedea și undefined. Este valoarea returnată de apel, nu o eroare. Mesajul tău apare separat.

4. Variabile: valori cu un nume

O variabilă ne permite să păstrăm o valoare și să o folosim după nume. În loc să repetăm prețul cafelei peste tot, scriem pretCafea.

const pretCafea = 12;
let cafeleVandute = 0;

cafeleVandute = 1;
console.log(pretCafea);     // 12
console.log(cafeleVandute); // 1
  • const: nu putem atribui ulterior altă valoare aceleiași variabile. Îi dăm o valoare de la început.
  • let: putem atribui altă valoare mai târziu, ca la un contor.
  • var: o formă mai veche de declarare, pe care o vei întâlni în cod existent. Pentru exercițiile noastre alegem const și let.
let numeClient;       // Declarare: creăm variabila; valoarea este undefined.
numeClient = "Mara";  // Atribuire: îi dăm o valoare.
numeClient = "Ana";   // Reatribuire: schimbăm valoarea.
const oras = "Iași";  // Declarare și inițializare într-un singur pas.

= înseamnă atribuire: valoarea din dreapta ajunge în variabila din stânga. Nu este o întrebare de tipul „sunt egale?”.

Nume care ne ajută să citim codul

Folosim camelCase: pretCafea, numeClient, esteDeschis. Numele nu conține spații, nu începe cu o cifră și nu poate fi un cuvânt rezervat, precum const. Literele, _ și $ sunt permise la început.

total și Total sunt nume diferite: JavaScript ține cont de majuscule.

Tu vinzi cafeaua, let ține scorul

Cafele vândute: 0

let cafeleVandute = 0;

// La fiecare click executăm:
cafeleVandute = cafeleVandute + 1;

Luăm valoarea veche, adăugăm 1 și păstrăm rezultatul. Variabila este declarată o singură dată, înainte de clickuri.

Pornește cu const. Folosește let dacă vei reatribui valoarea. La liste și obiecte vom vedea că const nu îngheață conținutul.

5. Tipuri de date: 12 și "12" nu sunt același lucru

Valoarea are un tip. Un preț este un număr, un nume este text, iar răspunsul la „este deschis?” poate fi adevărat sau fals.

Cele 7 tipuri primitive
TipExempluCe reprezintă
number12, 4.5Numere întregi și zecimale. În cod folosim punctul zecimal.
string"Cafea"Text între ghilimele.
booleantrue, falseAdevărat sau fals, fără ghilimele.
undefinedlet client;De exemplu, valoarea unei variabile declarate fără inițializare.
nulllet masa = null;Marcăm intenționat lipsa unei valori: încă nu am ales o masă.
bigint123nNumere întregi, inclusiv foarte mari. Deocamdată doar îl recunoaștem.
symbolSymbol("id")O valoare unică, utilă ca identificator. Nu avem nevoie de ea în exerciții.

Primitive înseamnă valori simple. Listele și obiectele, pe care le vedem imediat, pot grupa mai multe valori.

typeof: întrebăm ce tip are valoarea

console.log(typeof 12);       // "number"
console.log(typeof "12");     // "string"
console.log(typeof true);     // "boolean"
console.log(typeof undefined); // "undefined"
console.log(typeof null);     // "object" — o particularitate istorică!

typeof întoarce numele tipului sub formă de text. Deși rezultatul pentru null este "object", null este o valoare primitivă.

Detectivul de tipuri

typeof 12 → "number"

JavaScript are tipizare dinamică

let valoare = 12;
valoare = "douăsprezece"; // Permis: noua valoare are alt tip.

Nu declarăm un tip fix pentru variabilă. Totuși, numele și tipurile consecvente fac programul mai ușor de urmărit.

6. Numere și operatori: facem bonul

const pret = 12;
const cantitate = 3;
const total = pret * cantitate;
console.log(total); // 36

pret * cantitate este o expresie: produce o valoare. const total = pret * cantitate; este o declarație care păstrează acea valoare.

Operatorii aritmetici
OperatorRolExemplu → rezultat
+Adunare12 + 3 → 15
-Scădere12 - 3 → 9
*Înmulțire12 * 3 → 36
/Împărțire12 / 3 → 4
%Restul împărțirii13 % 3 → 1
**Ridicare la putere2 ** 3 → 8

Înmulțirea se face înaintea adunării: 2 + 3 * 4 este 14. Parantezele schimbă ordinea: (2 + 3) * 4 este 20.

let puncte = 10;
puncte += 5; // Același efect ca puncte = puncte + 5; acum 15.
puncte++;    // Adaugă 1; acum 16.
puncte--;    // Scade 1; acum 15.

Există și -=, *=, /=. Pentru început folosim ++ și -- separat, pe propria linie.

Bonul de la pauză

O cafea costă 12 lei. Câte cafele comandăm?

12 × 3 = 36 lei

Două rezultate surprinzătoare: NaN și Infinity 
console.log(Number("cafea")); // NaN: textul nu poate deveni un număr valid.
console.log(10 / 0);         // Infinity
console.log(typeof NaN);     // "number"

NaN înseamnă „Not a Number”, dar este o valoare specială a tipului number. Și Infinity aparține acestui tip.

7. Texte: mesaje care folosesc valorile noastre

Un string poate folosi ghilimele duble, simple sau backticks. Deschidem și închidem textul cu același semn.

const produs = "cafea";
const client = 'Mara';
const cantitate = 2;

console.log(client + " comandă " + cantitate + " cafele.");
console.log(`${client} comandă ${cantitate} cafele.`);
// Ambele afișează: Mara comandă 2 cafele.

Cu + lipim texte: operația se numește concatenare. Cu backticks (`) putem introduce valori sau calcule între ${ și }. Aceasta este o formă de template literal.

console.log(`Total: ${12 * 2} lei`); // Total: 24 lei
console.log("Prima linie\nA doua linie"); // \n trece pe o linie nouă.
console.log('Clientul a spus: "Mulțumesc!"');

Capcana lui +: text sau număr?

console.log(5 + 2);           // 7
console.log("5" + 2);         // "52"
console.log(Number("5") + 2); // 7

În aceste exemple, dacă un operand este text, + concatenează. Number() convertește explicit textul într-un număr; String() face conversia la text.

Valoarea citită prin input.value este text, inclusiv pentru un câmp type="number". O convertim înainte de calcule și verificăm datele. Atenție: Number("") produce 0, nu o eroare.

Ghicește înainte să deschizi: cât face "10" + 5 + 2?

"1052". Operațiile se fac de la stânga la dreapta: "10" + 5 produce "105", apoi se lipește și 2.

Cu paranteze, "10" + (5 + 2) produce "107". Cu conversie, Number("10") + 5 + 2 produce 17.

8. Arrays: mai multe valori într-o listă

Un array păstrează o listă ordonată. Îl scriem între [ ], cu elementele separate prin virgulă.

const meniu = ["Espresso", "Latte", "Ceai"];

console.log(meniu[0]);     // "Espresso"
console.log(meniu[1]);     // "Latte"
console.log(meniu.length); // 3
console.log(meniu[meniu.length - 1]); // "Ceai"
console.log(meniu[3]);     // undefined: nu există un element la indexul 3.

Indexul începe de la 0. O listă cu 3 elemente are indicii 0, 1 și 2. length spune câte elemente există.

Comandă după index

meniu[0] → "Espresso"

const produse = ["Espresso", "Latte"];
produse.push("Ceai"); // Adaugă la final.
produse[0] = "Decaf"; // Modifică primul element.
console.log(produse); // ["Decaf", "Latte", "Ceai"]

push() este o metodă: o funcție pe care o apelăm prin listă. Parantezele declanșează acțiunea; length este o proprietate și se citește fără paranteze.

const nu ne lasă să înlocuim lista cu alta prin produse = [...], dar putem modifica elementele listei existente.

Bonus mic: sortarea unei liste 
const bauturi = ["Latte", "Ceai", "Espresso"];
bauturi.sort();
console.log(bauturi); // ["Ceai", "Espresso", "Latte"]

sort() modifică lista existentă. Implicit compară elementele ca texte, deci [2, 10, 3].sort() produce [10, 2, 3]. Sortarea numerică o lăsăm pentru o lecție viitoare.

9. Obiecte: fișa unui produs

Un obiect grupează informații sub nume de proprietăți. Pentru un produs vrem să ținem împreună numele, prețul și disponibilitatea.

const cafea = {
  nume: "Latte",
  pret: 15,
  disponibil: true
};

console.log(cafea.nume); // "Latte"
console.log(cafea.pret); // 15
cafea.pret = 16;
console.log(cafea.pret); // 16

Folosim acolade { }. Fiecare pereche are forma proprietate: valoare; perechile sunt separate prin virgulă. Punctul din cafea.pret citește proprietatea pret.

const permite modificarea proprietăților obiectului existent, la fel ca la elementele unei liste.

Listă: „Ce produse avem?” → ["Latte", "Ceai"].
Obiect: „Ce știm despre un produs?” → { nume: "Latte", pret: 15 }.

10. Comparații: întrebări cu răspuns true sau false

console.log(12 > 10);     // true
console.log(12 < 10);     // false
console.log(12 >= 12);    // true
console.log(12 <= 10);    // false
console.log(12 === 12);   // true
console.log(12 !== 10);   // true
console.log(12 === "12"); // false: tipurile sunt diferite.

=== verifică egalitatea strictă, fără conversia tipurilor. !== verifică inegalitatea strictă. În exerciții le preferăm pe acestea.

console.log(5 == "5");  // true: == permite conversii de tip.
console.log(5 === "5"); // false: === nu face acele conversii.

= atribuie, === compară. pret = 12 schimbă prețul; pret === 12 întreabă dacă prețul este 12.

Legăm întrebările cu operatori logici

const esteDeschis = true;
const avemCafea = false;

console.log(esteDeschis && avemCafea); // false: trebuie să fie ambele true.
console.log(esteDeschis || avemCafea); // true: cel puțin una este true.
console.log(!esteDeschis);            // false: inversăm valoarea booleană.

&& înseamnă „și”, || înseamnă „sau”, iar ! înseamnă „nu”. Aici lucrăm cu valori booleene.

Ghicește: true && false || true

Rezultatul este true. && se evaluează înainte de ||: (true && false) || true devine false || true.

Folosește paranteze când vrei să arăți clar cum grupezi condițiile.

11. if / else: codul alege o variantă

Livrarea este gratuită de la 50 lei inclusiv. if execută blocul său când condiția este adevărată. else acoperă cealaltă situație.

const total = 36;

if (total >= 50) {
  console.log("Livrare gratuită!");
} else {
  console.log(`Mai adaugă produse de ${50 - total} lei pentru livrare gratuită.`);
}
// Mai adaugă produse de 14 lei pentru livrare gratuită.

Prinde pragul de livrare

Mai adaugă produse de 14 lei pentru livrare gratuită.

În acest demo folosim sume întregi. Încearcă 49, 50 și 51: la ce valoare se schimbă ramura?

Mai mult de două variante: else if

const ora = 14;

if (ora < 12) {
  console.log("Bună dimineața!");
} else if (ora < 18) {
  console.log("Bună ziua!");
} else {
  console.log("Bună seara!");
}
// Bună ziua!

Verificăm de sus în jos. Se execută doar prima ramură cu o condiție adevărată, sau else dacă niciuna nu este adevărată. Aici presupunem o oră validă, de la 0 la 23.

Truthy și falsy, fără mister

În condiții, și alte valori sunt interpretate ca adevărat sau fals. false, 0, -0, 0n, "", null, undefined și NaN sunt falsy. Un text nevid, de exemplu "Mara", este truthy.

const nume = "";
if (nume) {
  console.log(`Salut, ${nume}!`);
} else {
  console.log("Scrie un nume.");
}

console.log(Boolean(""));      // false
console.log(Boolean("false")); // true: este text nevid!
console.log(Boolean("0"));     // true: și acesta este text nevid.

Boolean() ne arată conversia la true sau false. Un spațiu, " ", este tot text nevid; verificarea din exemplu nu este o validare completă de formular.

12. Alte două moduri de a alege

switch: comparăm aceeași valoare cu mai multe variante

const marime = "M";

switch (marime) {
  case "S":
    console.log("Cafea mică");
    break;
  case "M":
    console.log("Cafea medie");
    break;
  case "L":
    console.log("Cafea mare");
    break;
  default:
    console.log("Alege S, M sau L.");
}
// Cafea medie

case este o variantă, comparată strict cu valoarea din switch. break oprește execuția acelui switch; fără el, codul poate continua în cazul următor. default se folosește când nimic nu se potrivește.

Operatorul ternar: alegem una dintre două valori

const total = 60;
const mesaj = total >= 50 ? "Livrare gratuită" : "Livrare cu plată";
console.log(mesaj); // "Livrare gratuită"

Citim: condiție ? valoareDacăDa : valoareDacăNu. Este util pentru alegeri scurte. Pentru mai mulți pași, if / else rămâne mai ușor de citit.

13. Bucle: repetăm fără copy-paste

Avem trei cafele de pregătit. În loc să scriem trei mesaje aproape identice, folosim o buclă.

for: pornire → condiție → cod → actualizare

for (let i = 1; i <= 3; i++) {
  console.log(`Pregătesc cafeaua ${i}`);
}
// Pregătesc cafeaua 1
// Pregătesc cafeaua 2
// Pregătesc cafeaua 3
  1. let i = 1: pornim contorul, o singură dată.
  2. i <= 3: înaintea fiecărei repetări verificăm condiția.
  3. Executăm codul dintre acolade.
  4. i++: adăugăm 1 și revenim la verificare. La 4, condiția devine falsă și ne oprim.

Barista la treabă

Alege cantitatea și urmărește fiecare repetare.

Parcurgem o listă cu for

const meniu = ["Espresso", "Latte", "Ceai"];

for (let i = 0; i < meniu.length; i++) {
  console.log(meniu[i]);
}
// Espresso, apoi Latte, apoi Ceai, pe linii separate.

Pornim de la 0 pentru primul index și folosim < meniu.length, nu <=, ca să nu citim dincolo de ultimul element.

while: repetăm cât timp condiția este adevărată

let cafeleRamase = 3;

while (cafeleRamase > 0) {
  console.log(`Mai am ${cafeleRamase} cafele de pregătit.`);
  cafeleRamase--;
}
console.log("Comanda este gata!");

Nu uita să actualizezi contorul. Fără cafeleRamase--, condiția ar rămâne adevărată și bucla ar continua fără oprire, blocând pagina.

do...while: executăm cel puțin o dată 
let cafeleRamase = 0;

do {
  console.log("Verific espressorul.");
} while (cafeleRamase > 0);
// Mesajul apare o dată, chiar dacă avem 0 cafele.

while verifică înaintea blocului. do...while verifică după bloc, deci prima execuție are loc întotdeauna.

14. O funcție: dăm un nume unei acțiuni

O funcție grupează cod pe care îl putem folosi de mai multe ori. Parametrii sunt numele intrărilor; return ne dă rezultatul și încheie apelul funcției.

function calculeazaTotal(pret, cantitate) {
  return pret * cantitate;
}

console.log(calculeazaTotal(12, 2)); // 24
console.log(calculeazaTotal(15, 3)); // 45

Definirea funcției nu face încă un calcul. O apelăm scriind numele și parantezele. Valorile concrete, precum 12 și 2, se numesc argumente.

return oferă o valoare codului care a apelat funcția; console.log() o afișează. Nu au același rol.

15. Legăm JavaScript de un buton real

DOM este reprezentarea elementelor paginii cu care putem lucra din JavaScript. Căutăm un element, ascultăm un eveniment și schimbăm textul.

În proiectul de la început, adaugă în <body>:

<button id="salut" type="button">Deschide cafeneaua</button>
<p id="mesaj" aria-live="polite">Aștept primul click.</p>

În script.js:

const buton = document.getElementById("salut");
const mesaj = document.getElementById("mesaj");

function deschideCafeneaua() {
  mesaj.textContent = "Bine ai venit! Ce cafea îți pregătim?";
}

buton.addEventListener("click", deschideCafeneaua);
  1. getElementById() găsește elementul după id, fără #.
  2. addEventListener() leagă evenimentul "click" de funcție.
  3. La click, browserul apelează funcția și textContent schimbă textul paragrafului.

La conectare scriem deschideCafeneaua fără (): îi dăm browserului funcția de apelat mai târziu. Cu () am executa-o imediat. Păstrează defer pe scriptul extern din <head>.

16. Greșeli mici, indicii utile

  • Nu apare mesajul? Verifică salvarea, calea din src și fila Console. console.log() nu scrie în pagină.
  • SyntaxError: verifică ghilimelele, parantezele și acoladele. Codul nu are o formă validă.
  • ReferenceError: verifică dacă ai declarat variabila și ai scris numele identic, inclusiv majusculele.
  • TypeError: poate apărea dacă reatribui un const sau încerci o operație nepotrivită pe o valoare.
  • Elementul găsit este null? Verifică id-ul și dacă scriptul rulează după ce HTML-ul a fost parcurs.
  • „Identifier has already been declared”? Ai declarat același nume de două ori în același bloc. Exemplele sunt independente: înlocuiește codul din script.js când treci la altul.

Trei întrebări înainte de pauză

1. Pot modifica pret într-un obiect declarat cu const?

Da: const produs = { pret: 12 }; urmat de produs.pret = 15; este valid. Nu putem reatribui variabila produs unui alt obiect.

2. O listă are 4 elemente. Care este ultimul index?

3, adică lista.length - 1. Primul index este 0.

3. De câte ori rulează for (let i = 0; i < 3; i++)?

De 3 ori, cu i egal cu 0, 1 și 2. La 3, condiția este falsă.

Temă simplă: legitimația de barista

Creează barista.html și barista.js, legate printr-un script extern cu defer. Lucrăm în consolă.

  1. Declară cu const un nume, băutura preferată și prețul ei.
  2. Declară cu let numărul de cafele pregătite, inițial 0.
  3. Crește contorul la 1 și apoi la 2.
  4. Afișează, folosind backticks, un mesaj cu numele, băutura și numărul de cafele.
  5. Calculează valoarea cafelelor pregătite și afișează dacă aceasta este cel puțin 20 lei, folosind o comparație.
  6. Afișează cu typeof tipul numelui și tipul prețului.

Pentru Mara, Latte și 12 lei: mesajul poate fi „Mara a pregătit 2 cafele. Preferata ei este Latte.” Totalul este 24, comparația cu 20 produce true, iar tipurile sunt "string" și "number".

Temă puțin mai complexă: bonul cafenelei

Creează cafenea.html și cafenea.js. Calculele și mesajele pot rămâne în consolă.

  1. Creează o listă cu trei obiecte: { nume: "Espresso", pret: 10, cantitate: 2 }, { nume: "Latte", pret: 15, cantitate: 1 } și { nume: "Ceai", pret: 8, cantitate: 1 }.
  2. Scrie funcția calculeazaSubtotal(pret, cantitate), care returnează produsul celor două valori.
  3. Pornește cu let total = 0;. Parcurge lista cu for, apelează funcția pentru fiecare produs și adună subtotalul în total.
  4. Pentru fiecare produs afișează un rând, de exemplu „Espresso × 2 = 20 lei”.
  5. Folosește if / else: livrare gratuită de la 50 lei, altfel livrarea costă 7 lei. Afișează totalul final, inclusiv livrarea.
  6. Schimbă numărul de Latte de la 1 la 2 și rulează din nou. Verifică ambele ramuri ale condiției.
Indiciu: cum arată o listă de obiecte?
const comanda = [
  { nume: "Espresso", pret: 10, cantitate: 2 },
  { nume: "Latte", pret: 15, cantitate: 1 },
  { nume: "Ceai", pret: 8, cantitate: 1 }
];

console.log(comanda[0].nume); // "Espresso"
// În buclă, comanda[i] este obiectul de la pasul curent.

Verificare: comanda inițială are produse de 43 lei și total final de 50 lei. Cu două Latte, produsele costă 58 lei, livrarea este gratuită și totalul final rămâne 58 lei. Pragul se verifică înainte să adaugi transportul.
