1. ES6 este o versiune a standardului JavaScript

ECMAScript este standardul care descrie regulile limbajului. JavaScript implementează aceste reguli. ES6 și ES2015 sunt două nume pentru aceeași ediție, publicată în 2015.

Ai folosit deja const, let și funcții arrow în lecțiile trecute. Acum vedem de ce sunt utile și adăugăm câteva idei noi.

  • ES2015: let, const, arrow functions, clase, template literals, spread pentru liste și apeluri, rest parameters și Promise.
  • ES2017: async / await.
  • ES2018: spread în obiecte.

Ultimele două apar în partea a doua a materialului și le includem aici, cu versiunea corectă. ES6 este un reper, nu numele tuturor noutăților JavaScript.

O scurtă recapitulare: texte cu valori în interior

const film = "Drum spre Marte";
const pret = 20;
const mesaj = `${film}: ${pret} lei / bilet`;
console.log(mesaj); // "Drum spre Marte: 20 lei / bilet"

Un template literal folosește backticks (`), iar ${...} introduce o valoare sau un calcul în text. Vom folosi această formă în exemple.

2. const pentru început, let când reatribuim

const pretBilet = 20;
let numarBilete = 2;

numarBilete = 3; // Variabila primește altă valoare.
console.log(pretBilet * numarBilete); // 60

// pretBilet = 25; // TypeError: un const nu poate fi reatribuit.

Alege const când variabila va păstra aceeași valoare sau aceeași referință. Alege let când urmează o reatribuire, de exemplu pentru un contor sau un total acumulat.

Block scope: variabila aparține blocului în care o declari

Un bloc este o zonă delimitată de acolade, de exemplu corpul unui if. Variabilele declarate acolo cu let sau const sunt accesibile în acel bloc și în blocurile din interior.

const pret = 20;

if (true) {
  const reducere = 5;
  const pret = 15; // Altă variabilă, doar pentru acest bloc.
  console.log(pret, reducere); // 15 5
}

console.log(pret); // 20: variabila din exterior nu s-a schimbat.
// console.log(reducere); // ReferenceError: în afara blocului.

Exemplul repetă intenționat numele pret ca să arate limita blocului. În codul obișnuit, nume precum pretRedus sunt mai ușor de urmărit.

De recunoscut în cod mai vechi: var

var are scope de funcție, nu de bloc. Un if nu îi creează un domeniu separat.

function exempluVar() {
  var pret = 20;
  if (true) {
    var pret = 15; // Aceeași variabilă din funcție.
  }
  console.log(pret); // 15
}

exempluVar();

Pentru exercițiile noi folosim let și const. Nu înlocui mecanic fiecare var din cod vechi: limitele de vizibilitate pot schimba comportamentul.

const nu îngheață obiectele și listele

const bilet = { film: "Drum spre Marte", pret: 20 };
bilet.pret = 25; // Modificăm o proprietate a aceluiași obiect.
console.log(bilet.pret); // 25

const filme = ["Drum spre Marte"];
filme.push("Pisica regizor");
console.log(filme.length); // 2

// bilet = { film: "Alt film", pret: 10 }; // TypeError.
// filme = []; // TypeError: am încerca să înlocuim lista.

Reatribuirea schimbă valoarea păstrată în variabilă. Modificarea unei proprietăți sau un push() schimbă conținutul obiectului existent. const împiedică prima operație.

3. Hoisting: declarăm înainte să folosim

Înainte să execute instrucțiunile unui domeniu, JavaScript pregătește declarațiile. Numim acest comportament hoisting; codul nu este mutat fizic în fișier.

console.log(titluVechi); // undefined
var titluVechi = "Drum spre Marte";
console.log(titluVechi); // "Drum spre Marte"

// console.log(titluNou); // ReferenceError dacă decomentezi linia.
let titluNou = "Pisica regizor";
console.log(titluNou); // "Pisica regizor"

Cu var, variabila este inițializată cu undefined înainte de linia declarației. Cu let și const, nu o putem accesa până când execuția ajunge la declarație. Acea perioadă se numește temporal dead zone.

undefined este o valoare. ReferenceError este o eroare de execuție; fără tratare, oprește execuția curentă. O variabilă nedeclarată nu este creată automat când încerci să o citești.

Opțional: de ce typeof poate să ne surprindă? 
console.log(typeof variabilaCareNuExista); // "undefined"
// console.log(variabilaCareNuExista); // ReferenceError.

// console.log(typeof locuri); // Tot ReferenceError: temporal dead zone.
const locuri = 8;

typeof are un comportament special pentru un nume nedeclarat. Acesta nu se aplică unei variabile let sau const înainte de inițializare.

Regula practică: scrie declarația înaintea folosirii. Procedează la fel cu o clasă și cu o funcție păstrată într-un const. O declarație obișnuită function poate fi apelată și înainte de linia ei.

4. Arrow functions: de la forma lungă la cea scurtă

Funcțiile următoare fac același calcul. Schimbăm doar felul în care îl scriem.

const totalClasic = function (pret, cantitate) {
  return pret * cantitate;
};

const totalArrow = (pret, cantitate) => {
  return pret * cantitate;
};

const totalScurt = (pret, cantitate) => pret * cantitate;

console.log(totalClasic(20, 3)); // 60
console.log(totalArrow(20, 3));  // 60
console.log(totalScurt(20, 3));  // 60
  • Fără acolade, expresia de după => este returnată automat.
  • Cu acolade, scrie return dacă ai nevoie de un rezultat.
  • La un singur parametru simplu poți omite parantezele: pret => pret * 2.
  • La zero sau mai mulți parametri, parantezele sunt obligatorii.

Un callback mic pentru o listă de prețuri

const preturi = [20, 25, 30];
const preturiReduse = preturi.map(pret => pret - 5);

console.log(preturiReduse); // [15, 20, 25]
console.log(preturi);       // [20, 25, 30]

map() creează o listă nouă din rezultatul fiecărui apel. Aici, fiecare preț este redus cu 5 lei.

Două capcane mici

const faraReturn = (pret) => { pret * 2; };
console.log(faraReturn(20)); // undefined: lipsește return.

const creeazaBilet = (film, pret) => ({ film: film, pret: pret });
console.log(creeazaBilet("Drum spre Marte", 20));
// { film: "Drum spre Marte", pret: 20 }

Când returnezi direct un obiect, învelește-l în (). Altfel, acoladele sunt interpretate drept corpul funcției. Păstrează => pe aceeași linie cu lista parametrilor.

5. this: arrow preia contextul din exterior

O funcție arrow nu are propriul this. Îl preia din contextul în care a fost creată. Este utilă ca funcție mică în interiorul unei metode.

const cinema = {
  nume: "Cinema Central",
  filme: ["Drum spre Marte", "Pisica regizor"],
  creeazaEtichete() {
    return this.filme.map(film => `${this.nume}: ${film}`);
  }
};

console.log(cinema.creeazaEtichete());
// ["Cinema Central: Drum spre Marte", "Cinema Central: Pisica regizor"]

Apelăm metoda prin cinema.creeazaEtichete(), deci this din metodă este obiectul cinema. Callbackul arrow folosește același this.

Pentru o metodă care citește proprietăți prin this, păstrează forma metoda() { ... }. Nu o transforma automat într-o proprietate cu arrow. Într-un listener arrow pentru DOM, folosește event.currentTarget dacă ai nevoie de elementul pe care ai pus listenerul.

6. Clase: aceeași structură pentru mai multe bilete

Un obiect literal este suficient pentru un singur bilet. O clasă descrie cum creăm mai multe obiecte cu aceleași tipuri de date și aceleași metode.

class Bilet {
  constructor(film, pret) {
    this.film = film;
    this.pret = pret;
  }

  calculeazaTotal(cantitate = 1) {
    return this.pret * cantitate;
  }
}

const primul = new Bilet("Drum spre Marte", 20);
const alDoilea = new Bilet("Pisica regizor", 15);

console.log(primul.film);               // "Drum spre Marte"
console.log(primul.calculeazaTotal(3)); // 60
console.log(alDoilea.calculeazaTotal()); // 15
  1. class Bilet definește clasa. Prin convenție, numele începe cu literă mare.
  2. new Bilet(...) creează un obiect nou, numit instanță.
  3. constructor setează datele inițiale. Aici, this este noul obiect.
  4. calculeazaTotal() este o metodă apelată printr-o instanță.
  5. cantitate = 1 este o valoare implicită: se folosește dacă argumentul lipsește sau este undefined.

Cele două obiecte au propriile valori pentru film și preț. Clasele folosesc mecanismul de prototipuri al JavaScript; nu trebuie să îl aprofundăm pentru acest exercițiu.

Testează metoda pentru un bilet de 20 lei

Drum spre Marte: 2 × 20 lei = 40 lei

Formularul citește cantitatea cu Number(), verifică dacă este un întreg între 1 și 10, apoi apelează metoda de mai sus. Vezi codul celor două demonstrații.

Opțional: getter, setter și o metodă statică

Un getter se citește ca o proprietate, fără (). Un setter se execută la atribuire. O metodă statică se apelează pe clasă.

class Film {
  constructor(titlu) {
    this.titlu = titlu; // Apelează setterul de mai jos.
  }

  get titlu() {
    return this._titlu;
  }

  set titlu(valoare) {
    this._titlu = valoare.trim();
  }

  static descriere() {
    return "Un film din programul cinematografului.";
  }
}

const film = new Film("  Drum spre Marte  ");
console.log(film.titlu); // "Drum spre Marte"
film.titlu = "  Pisica regizor  ";
console.log(film.titlu); // "Pisica regizor"
console.log(Film.descriere()); // "Un film din programul cinematografului."
// film.descriere(); // TypeError: metoda statică aparține clasei.

În acest exemplu, titlul primit este un șir de caractere. _titlu este un nume ales prin convenție, nu o proprietate privată. Folosim alt nume în setter ca să nu apelăm același setter la nesfârșit.

Opțional: extends și super

O clasă poate extinde alta. Exemplul continuă clasa Bilet de mai sus și adaugă prețul unui meniu.

class BiletCuMeniu extends Bilet {
  constructor(film, pret, pretMeniu) {
    super(film, pret);
    this.pretMeniu = pretMeniu;
  }

  calculeazaTotal(cantitate = 1) {
    return super.calculeazaTotal(cantitate) + this.pretMeniu * cantitate;
  }
}

const bilet = new BiletCuMeniu("Drum spre Marte", 20, 5);
console.log(bilet.calculeazaTotal(2)); // 50: două bilete și două meniuri.

extends stabilește legătura cu clasa de bază. În constructorul clasei derivate, super(...) apelează constructorul părinte înainte de folosirea lui this. În metodă, super.calculeazaTotal(...) refolosește calculul părintelui.

7. Spread: desfacem elementele acolo unde avem nevoie de ele

Sintaxa ... poate introduce elementele unei liste într-o altă listă sau într-un apel de funcție.

Combinăm liste fără să le modificăm pe cele inițiale

const vineri = ["Drum spre Marte", "Pisica regizor"];
const sambata = ["Pauză de râs"];
const weekend = [...vineri, ...sambata];

console.log(weekend);
// ["Drum spre Marte", "Pisica regizor", "Pauză de râs"]
console.log(vineri.length); // 2

const listaMea = [...vineri];
listaMea.push("Aventura din parc");
console.log(listaMea.length); // 3
console.log(vineri.length);  // 2

const listaMea = vineri ar păstra o referință către aceeași listă. [...vineri] creează o listă nouă. Spread nu elimină elementele duplicate.

Trimitem elementele unei liste ca argumente separate

const preturi = [20, 15, 30];
console.log(Math.max(...preturi)); // 30
// Echivalent cu Math.max(20, 15, 30).

Spread în obiecte: copiere și actualizare (ES2018)

const bilet = { film: "Drum spre Marte", pret: 20 };
const biletRedus = { ...bilet, pret: 15 };

console.log(biletRedus); // { film: "Drum spre Marte", pret: 15 }
console.log(bilet.pret); // 20

Dacă o proprietate apare de mai multe ori, ultima valoare câștigă. În { pret: 15, ...bilet }, prețul ar redeveni 20.

Atenție: copia este superficială 
const original = [{ titlu: "Drum spre Marte" }];
const copie = [...original];
copie[0].titlu = "Titlu schimbat";

console.log(original[0].titlu); // "Titlu schimbat"

Lista este nouă, dar obiectul din interior este același. Și spread în obiecte copiază doar primul nivel. În exemplele de copiere independentă de mai sus, listele conțin texte, iar obiectul conține doar texte și numere.

8. Rest: primim mai multe argumente într-o singură listă

În lista de parametri a unei funcții, ... adună argumentele rămase într-un array.

function adunaPreturi(...preturi) {
  let total = 0;
  for (const pret of preturi) {
    total += pret;
  }
  return total;
}

console.log(adunaPreturi(20, 15, 30)); // 65
console.log(adunaPreturi(20));         // 20
console.log(adunaPreturi());           // 0

const bon = [20, 15, 30];
console.log(adunaPreturi(...bon));     // 65

În declarația funcției, ...preturi este rest: strânge argumentele. În ultimul apel, ...bon este spread: desface lista în argumente.

  • Lista [20, 15, 30]
  • Spread → argumentele 20, 15, 30
  • Rest → parametrul preturi, un array

Un parametru rest trebuie să fie ultimul și poate apărea o singură dată în lista parametrilor: function bon(nume, ...preturi) { ... }. În calculele noastre trimitem numere, nu texte precum "20".

9. Promise: rezultatul nu este disponibil imediat

La un calcul simplu obținem rezultatul pe loc. La o operație asincronă, cum ar fi o cerere către un server, rezultatul vine mai târziu. Un Promise reprezintă finalizarea acelei operații.

  • pending: operația nu s-a încheiat.
  • fulfilled: operația s-a încheiat cu succes și avem o valoare.
  • rejected: operația a eșuat și avem un motiv al erorii.

O promisiune trece din pending într-una dintre celelalte două stări. După aceea, starea ei nu se mai schimbă.

Simulăm o verificare, fără server

function verificaLocuri(disponibil) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (disponibil) {
        resolve("Sunt locuri disponibile.");
      } else {
        reject(new Error("Nu mai sunt locuri la acest film."));
      }
    }, 1000);
  });
}

setTimeout programează callbackul după aproximativ 1000 ms. resolve() oferă valoarea de succes; reject() semnalează eșecul. new Error(...) creează un obiect de eroare cu proprietatea message.

Funcția întoarce imediat promisiunea. Textul va fi disponibil abia după terminarea verificării. Întârzierea este simulată; nu facem o rezervare reală.

then și catch: ce facem cu rezultatul?

Rulează fragmentul următor după definiția lui verificaLocuri.

console.log("1. Începem verificarea.");

verificaLocuri(true)
  .then(mesaj => {
    console.log(`3. ${mesaj}`);
  })
  .catch(eroare => {
    console.log(eroare.message);
  });

console.log("2. Putem continua cu alt cod.");
// Imediat: 1. Începem verificarea.
// Imediat: 2. Putem continua cu alt cod.
// Mai târziu: 3. Sunt locuri disponibile.

.then() tratează succesul. .catch() tratează respingerea promisiunii sau o eroare apărută în callbackul precedent. Înlocuiește true cu false și vei vedea mesajul din catch.

verificaLocuri(true) întoarce un Promise, nu textul rezultat. Nu putem citi textul imediat după apel ca și cum operația s-ar fi terminat deja.

10. async / await: citim pașii în ordine

async / await lucrează tot cu promisiuni. Într-o funcție async, await suspendă continuarea acelei funcții până când promisiunea se încheie. Pagina poate răspunde în continuare la interacțiuni.

Acest fragment folosește aceeași funcție verificaLocuri din secțiunea precedentă.

async function afiseazaDisponibilitate(disponibil) {
  try {
    const mesaj = await verificaLocuri(disponibil);
    console.log(mesaj);
  } catch (eroare) {
    console.log(eroare.message);
  }
}

afiseazaDisponibilitate(true); // Mai târziu: "Sunt locuri disponibile."
// Încearcă apoi afiseazaDisponibilitate(false).

try conține pașii pe care îi încercăm. Dacă promisiunea este respinsă, await produce o eroare, iar execuția trece în catch.

O funcție async întoarce întotdeauna o promisiune, chiar dacă scrii return 20. În exemplele noastre, scriem await doar în interiorul unei funcții async.

Vezi legătura dintre demo și cod

Pe lângă verificaLocuri, folosim elementele cu ID-urile din demonstrație. finally rulează atât după succes, cât și după eroarea tratată, pentru a reactiva controalele.

const butonVerifica = document.getElementById("verifica-locuri");
const scenariu = document.getElementById("scenariu");
const stare = document.getElementById("stare-promisiune");

butonVerifica.addEventListener("click", async () => {
  const disponibil = scenariu.value === "disponibil";
  butonVerifica.disabled = true;
  scenariu.disabled = true;
  stare.textContent = "pending: verificăm locurile…";

  try {
    const mesaj = await verificaLocuri(disponibil);
    stare.textContent = `fulfilled: ${mesaj}`;
  } catch (eroare) {
    stare.textContent = `rejected: ${eroare.message}`;
  } finally {
    butonVerifica.disabled = false;
    scenariu.disabled = false;
  }
});

Butonul este dezactivat în timpul așteptării, ca să nu pornim aceeași verificare de mai multe ori. Pentru o pagină separată, copiază și HTML-ul demonstrației și funcția verificaLocuri, apoi încarcă scriptul cu defer.

Temă simplă: bonul pentru seara de film

Lucrează într-un fișier tema-es6-1.js, încărcat într-un HTML cu defer. Este suficient să afișezi rezultatele în consolă.

const bilete = [20, 15];
